PraNam E-Invoice Converter 2.2

Implemented offline validation upgrades:
- Bundled e-Invoice JSON Schema 1.1 validation before generation and again after JSON is written.
- Optional null fields are omitted from generated JSON.
- Offline GST/IRP checks for GSTIN format/equality, supply type, RCM, IGST-on-intra, state/POS, item count, duplicate Sl.No., tax logic, GST rate master and invoice date/reporting warning.
- Check screen includes Supplier GSTIN, Reverse Charge, IGST on Intra-State and offline 30-day-rule flag.
- Live GST/IRP checks are intentionally not implemented.

The supplied NIC/GePP workbook schema is used as the bundled Schema 1.1 baseline. Current 40% GST rate is included in the local rate master.
