PRA NAM E-INVOICE CONVERTER v2.2.8

1. Install Python 3.11+ once.
2. Double-click install_requirements.bat once.
3. Double-click run_app.bat.
4. Click "Select Invoice & Generate" and select an invoice (.xlsx, .xlsm, .pdf or .docx).
5. If the Check / Correct screen appears, correct the flagged fields and use Re-check.
6. Generate only after all blocking issues are cleared.

Output files are written to the Output folder.

For scanned PDFs/images, install Tesseract OCR once. See README.md for details.
