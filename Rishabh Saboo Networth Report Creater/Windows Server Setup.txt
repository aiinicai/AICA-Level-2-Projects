NET WORTH OFFICE - WINDOWS SERVER SETUP

1. Extract the ZIP on the Windows server.
2. Optional: to move your existing reports, double-click Export Net Worth
   Backup.cmd on the old PC in the working app folder. Copy the resulting
   networth-backup.sqlite3 into the extracted setup folder on the server.
3. On the server, double-click Setup Net Worth Office.cmd. Approve Windows'
   administrator prompt. Setup installs the libraries, starts the app,
   and displays the browser link for staff on the private office subnet.

Setup needs internet access for dependencies. If Python is missing, setup
tries Windows Package Manager. On servers without it, install Python 3.13
for all users and rerun setup.

The installed app and database are in ProgramData\Net Worth Office.
Setup registers a Windows startup task to run the app after reboot.
Use the staff link only on the trusted private LAN. It uses HTTP and the
app has no staff sign-in. Do not expose this port to the public internet.

For valuation extraction, set GEMINI_API_KEY as a Windows system
environment variable and restart the Net Worth Office task. The export
contains Windows-protected SSP credentials, which stay tied to the old
Windows account. Automatic ICAI browser automation is unavailable in this
background server setup. Use the manual ICAI option in Prepare UDIN.

The installer ZIP contains software only. Keep report backups private.
