WHAT IS NEW IN REVISED 43

FIX: MANAGER APPROVAL NOT VISIBLE (large certificate PDF)
- Big files are now stored separately, so the small approval record always reaches the Manager.
- Accountant sees "Submitted and saved" or a clear warning if it could not be shared.
- Manager: Demand Schedule tab shows an approval inbox with a "Check for new submissions" button.
- Accountant and Manager must use the SAME browser and profile on the same computer (not Incognito).

NEW IN THIS VERSION (AI narration matching)
- Upload Bank Statement tab: unmatched receipts now show an "AI suggest" button (and "AI suggest for all unmatched").
- The AI (Claude via n8n workflow "Miles2Collect - Bank Receipt AI Matching" in the NEW n8n account hjsaccts.app.n8n.cloud) only SUGGESTS a flat with a reason and confidence.
  Nothing is applied until the Accountant clicks Accept. Below 70% confidence there is no Accept button.
- Guards: the AI may pick only from the sold-flat list; a flat outside the list is discarded; vague names
  (for example only "MEHTA") return no match; offline or n8n down = manual assignment still works.
- Settings: Demand Workflow > "Letterhead and n8n connection" > "AI narration-matching webhook (n8n)".
  The URL is pre-filled in this version (https://hjsaccts.app.n8n.cloud/webhook/slab2cash-narration-ai).
  Paste the shared token in the "token" field (not included in this ZIP). Old browser-stored URLs override the pre-filled one: overwrite and Save.
- Test file: demo_flow/09_Bank_Statement_AI_Narration_Matching.csv (upload it as a bank statement:
  3 AI matches, 3 correct refusals; flat 301 line is matched by rules, not AI).
- Principle for the panel: AI proposes, rules verify, human approves.
  - Wrong, out-of-sequence or future-dated certificate stops the stepper at 'Certificate read' (red); 'Remove certificate' / 'Replace' lets you upload the right one.
  - Stepper shows 'Awaiting Manager' while approval is pending. After demands are prepared, the next milestone's certificate can be uploaded (same workflow).
  - Dashboard: demand and outstanding cards reconcile to stages achieved; collection-efficiency formula and RERA data sources are shown; the P&L card is removed (Profit & Loss tab stays).
  - GST wording: 5% without ITC (CGST 2.5% + SGST 2.5%; IGST 5% inter-State). Interest: standard 12% p.a. simple (Project Info row 'Interest Rate % p.a.').
  - Demand letter: new Tax Invoice-cum-Demand layout (preview and PDF).
  - The 8-slide deck and presenter guide were not part of the Revised 42 package; update them for the points above (interest 12%, no P&L card, new letter).
