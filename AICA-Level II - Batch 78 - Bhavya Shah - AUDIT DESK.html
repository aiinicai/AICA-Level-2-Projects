Client Master

Maintain each client once; bulk preparation uses these records.
One-sheet import: put both client and engagement data in the Clients workbook. Repeating the same client on multiple rows adds multiple distinct engagements to the same client without duplicating the client. The import runs through Review → Verify Data → Import. Duplicate PAN/CIN/GSTIN values across different companies are blocked.

Engagement Master

One client can have multiple engagements, e.g. FY 2025-26 statutory audit.
Import can match clients using Client ID or Client Name. Supported fields: Financial Year, Engagement Type, Appointment Date, AGM Date, Audit Fee, Previous Auditor, Previous Auditor M.No., Previous Auditor Address, Place, FY End.
🗂 Template Manager
Your eight prebuilt audit templates are included and editable. New DOCX files can be imported, and any imported DOCX can be converted into a browser-editable copy. Browser-edited templates are stored separately from the application source and can be duplicated, renamed or deleted.

✨ Template Builder

Create a supported template from a natural-language brief or from a sample Word document. A sample is converted into a browser-editable template with its placeholders retained. Prompt drafting uses AuditDesk's built-in CA document structure and placeholder library; it creates a draft you can edit before using it for final documents.
