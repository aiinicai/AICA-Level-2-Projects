📋 Standard Operating Procedure
ITR Preparation — Non-Audit Cases
Step-by-step workflow for preparing and filing Income Tax Returns for non-audit clients — from reviewing last year's ITR through to final filing and archival. Written for freshers and trainees. (Software Used: Computax)
📌 Version 1.0 📅 Modified 23 Jun 2026 👥 Owner: Direct Tax Team
How to use this document: This SOP is written for FRESHERS / TRAINEES with no prior experience in ITR preparation. Follow each step in the exact sequence given. Do not skip a step even if you think a case is "simple". If you are unsure at ANY point, STOP and ask your reporting senior — do not guess and proceed. This SOP applies only to NON-AUDIT cases (i.e., cases where tax audit under Section 44AB is not applicable).

1. Purpose and Scope

This SOP lays down the step-by-step process to be followed by every team member — fresher or experienced — while preparing and filing Income Tax Returns (ITR) for Non-Audit clients of the firm. The objective is to ensure consistency, accuracy, traceability, and a uniform filing standard across all client files, regardless of who in the team is working on the file.

This SOP applies to:

  • Individual clients (salary, house property, capital gains, other sources)
  • Proprietorship / business and professional clients NOT liable to tax audit under Section 44AB
  • Presumptive taxation cases (Section 44AD / 44ADA / 44AE)
  • HUF and small firms not liable to audit
Scope note: This SOP does NOT apply to tax audit cases, scrutiny/assessment matters, or appellate matters — those are governed by separate SOPs.

2. General Rules — Applicable Throughout the Engagement

2.1 Client Communication Protocol

MANDATORY: All client communication — calls, WhatsApp, and emails — must be made ONLY through the official firm landline/mobile number and the official firm email ID allotted to you. Personal mobile numbers or personal email IDs must NEVER be used to contact a client for any purpose — not even for a "quick reminder" or because it feels faster. If you do not have an official number/email allotted yet, inform your reporting senior before initiating any client contact. Every email sent to a client must be marked CC to your reporting senior / the engagement partner, unless your senior instructs otherwise.

2.2 File Naming Protocol — Applicable to Every Document

Every file saved on the office system or client server — whether received from the client, scanned by us, or generated by us during the course of ITR preparation — must be named using the following structure. This is non-negotiable and applies uniformly across all document types.

[Document Type] - [AY] - [Client Name]

Separator: a single dash/hyphen ( - ) with spaces on both sides, between each part

Rules for the naming protocol:

  • Client Name must match the name used in the firm's client master / Computax client master exactly — do not use nicknames or shortened versions.
  • If a document needs a version number (e.g., revised computation), add it at the end: COI – AY-2627 - ClientName - Rev1

2.3 Folder Roll-Over Protocol (Year-on-Year)

At the start of every new Assessment Year, the client's folder must be rolled over from the previous year using the following method — do not start a fresh folder from scratch.

  • Only Standard Folders should be there
  • CREATE folder in the current AY's folder with the same name as of last year
  • In that, create "Data Recd for ITR or Accounting" for saving files received from client
  • Folder "Working Folder" for saving working files
  • Folder "26AS / AIS / TIS" for saving AIS / TIS / Form 26AS and its related working
  • Copy (not move) the STATEMENT FILE ONLY of previous year's file into the newly created client folder for the current AY
  • Rename the copied files to reflect the current AY, following the File Naming Protocol at clause 2.2
  • Begin working on the copied files for the current year — update figures, references, and annexures as applicable. Do not delete prior-year content; retain it for reference within that year's working file unless your senior instructs cleanup

Quick-access shortcuts (mandatory in every current-year client folder):

  • Create a shortcut/link to the LAST YEAR'S folder inside the current year's folder, and rename this shortcut to start with the letter 'Z' (e.g., Z_LastYearFolder) so it sorts to the bottom of the folder view and does not get confused with current-year working files
  • Similarly, create a shortcut/link to the relevant Tally data folder inside the current year's folder, and rename it to also start with 'Z' (e.g., Z_TallyData)

This keeps prior-year reference material and Tally data easily accessible without cluttering the active working files of the current year.

3. Step-by-Step Workflow

Follow the phases below strictly in sequence. Each phase has a checklist. Tick off every checklist item physically or digitally before moving to the next phase. Do not jump ahead.

1PHASE 1: Case Opening — Review of Last Year's ITR

Before asking the client for anything, first understand the client from what the firm already has on record. This avoids asking the client for information we already possess, and helps you understand what to expect this year.

  • Open the client's folder for the immediately preceding Assessment Year (use the roll-over folder set up per clause 2.3)
  • Locate and open last year's filed ITR (the ITR-V / ITR-Ack) and last year's Computation of Income (COI file)
  • Note down: which ITR Form was used last year (ITR-1/2/3/4 etc.) and why (nature and sources of income)
  • Note down each head of income reported last year: Salary, House Property, Business/Profession (and whether presumptive u/s 44AD/44ADA/44AE or regular books), Capital Gains, Other Sources
  • Note down deductions claimed last year (Chapter VI-A – 80C, 80D, 80G, 80TTA/80TTB, etc.) and any carried-forward losses from earlier years that may need to be set off this year
  • Note down the tax regime opted last year (Old Regime / New Regime) and whether Form 10-IEA (opting out of new regime, where applicable) was filed
  • Check if last year's return was filed within the original due date, as a belated return, or revised — this affects what is permissible this year (e.g., carry-forward of certain losses is allowed only if the original return was filed on time)
  • Check if there is any pending notice, intimation u/s 143(1), refund status, or outstanding demand from any earlier year that needs to be tracked or informed to the client
  • Prepare a one-line internal note summarising the above for quick reference while preparing the current year's computation
New client note: If this is a NEW client with no prior ITR on file with the firm, import all earlier filed ITRs from the IT portal into Computax and instead request last year's ITR copy (ITR-V/Ack) and Computation of Income directly from the client as part of the document list in Phase 3. If it is the client's first return, skip this phase.

2PHASE 2: Review of Form 26AS / AIS / TIS for the Current Year

This step tells you what income and tax credits the Income Tax Department already has on record for the client for the current Assessment Year — BEFORE you ask the client for documents. This helps you ask the client targeted questions instead of generic ones.

  • Log in to the Income Tax e-filing portal using the client's credentials (or through the firm's authorised access, as per office practice) and download: Form 26AS, AIS, and TIS for the relevant Assessment Year
  • Save all three using the File Naming Protocol (clause 2.2) in the current year's client folder
  • Go through Form 26AS and list out every TDS/TCS entry: deductor name, section under which tax was deducted, amount of income/payment, and TDS amount
  • Go through AIS/TIS and list out all additional information reported that is NOT in Form 26AS — commonly: interest from savings/FDs, dividend income, mutual fund/securities transactions, sale/purchase of immovable property, foreign remittances, GST turnover (if applicable), credit card spends, etc.
  • Compare current year's AIS/TIS entries with last year's pattern (from Phase 1). Flag anything that is naturally recurring but missing this year, and anything new that has appeared this year — both are points to specifically ask the client about
  • Prepare a simple list/sheet of 'Income Sources Indicated by 26AS/AIS/TIS' — this becomes a checklist while collecting documents and while preparing the computation, to ensure nothing reported to the Department is missed in the return
Important: Common fresher mistake — relying only on Form 26AS and ignoring AIS/TIS. AIS/TIS contains many income items (savings interest, dividend, securities transactions) that do NOT appear in 26AS. Always check all three. If any AIS entry appears clearly incorrect or duplicated, do NOT alter the return based on assumption — raise it with your senior; the client may need to file feedback on the AIS portal first.

3PHASE 3: Preparing the Document Request List & Collecting Documents from Client

Based on Phase 1 (last year's pattern) and Phase 2 (26AS/AIS/TIS for this year), prepare a specific document request list for this client — not a generic one. Then contact the client only through official channels (clause 2.1).

3.1 Standard documents to request in every case

  • PAN card and Aadhaar card (if not already on file, or if any change)
  • Bank statements for all bank accounts held during the financial year (savings, current, joint accounts where client is a holder)
  • Form 16 (if salaried) for the relevant financial year
  • Details of any investments made for tax-saving deductions (80C, 80D, 80G, etc.) with supporting receipts/certificates
  • Details of housing loan interest certificate, if applicable
  • Details of any property bought/sold during the year, with sale deed/purchase deed and relevant valuation, if applicable
  • Details of any new loans taken or closed during the year
  • Last year's ITR copy and computation, if the client is new to the firm and this was not already available internally

3.2 Additional documents based on Phase 1 & Phase 2 findings

  • For every income head identified in last year's return — request the corresponding current-year supporting document (e.g., rent agreement and municipal tax receipt if House Property income was reported last year)
  • For every new item flagged in AIS/TIS this year that was not present last year — specifically ask the client to explain/confirm and provide supporting documents (e.g., mutual fund statement, property sale documents, foreign remittance details)

4PHASE 4–5: Computation & ITR Form Selection

  • Income from Other Sources — interest income, dividend income, and any other item identified from AIS/TIS or client documents
  • Claim all eligible deductions under Chapter VI-A (80C, 80D, 80G, 80TTA/80TTB, etc.) strictly based on supporting documents/receipts provided by the client — do not claim any deduction without proof on file
  • Verify set-off and carry-forward of losses (if any) from earlier years against the figures noted in Phase 1, ensuring such set-off is permissible under the applicable provisions and time limits
  • Select the correct ITR Form based on the client's sources of income, status, and applicability (Computax will assist in identifying the correct form, but you must verify it manually against the facts of the case)
  • Evaluate tax liability under both the Old Regime and the New Regime in Computax (where the comparison is relevant for the client's category) and confirm with your senior which regime is to be opted for this client, including whether Form 10-IEA needs to be filed
  • Let Computax auto-calculate interest under Sections 234A/234B/234C and late filing fee under Section 234F, where applicable, and verify these figures appear correctly in the computation
  • Generate the Computation of Income from Computax and save it per the naming protocol: COI - AY-XXYY - ClientName

6PHASE 6: Internal Review / Quality Check (Before Filing)

No return is to be filed without this review step. A fresher must get the file reviewed by the reporting senior; freshers should not mark a file 'ready to file' on their own.
  • Cross-check every figure in the Computation of Income against the source document (bank statement, Form 16, 26AS/AIS/TIS, Trial Balance/Receipts & Payments, etc.). There must be a document on file supporting every figure entered
  • Cross-check TDS/TCS claimed in the return against Form 26AS — ensure no credit is claimed that is not reflected in 26AS, unless specifically discussed with your senior
  • Re-check the AIS/TIS list prepared in Phase 2 against the final computation — confirm every item has either been included in the return or has a documented, valid reason for exclusion
  • Verify PAN, bank account number, and IFSC code entered in the return (for refund credit) are correct and match the client's records
  • Verify the correct ITR Form, Assessment Year, and tax regime have been selected
  • Check that all mandatory schedules applicable to the case (e.g., Schedule AL, Schedule CG, Schedule BP, foreign assets/income disclosure if applicable) have been completed
  • Send the draft Computation of Income to your reporting senior for review, along with a note on any open queries or unusual items noticed
  • Incorporate all review comments received from your senior and re-verify the figures after making corrections
  • Once your senior confirms the file is correct, share the final Computation of Income with the client for their confirmation/approval before filing, using only the official communication channel (clause 2.1)
  • Obtain the client's clear confirmation (email/WhatsApp reply) approving the figures before proceeding to file the return. Save this confirmation in the client folder

7PHASE 7: Filing the Return and Saving Acknowledgements

  • Log in to the Income Tax e-filing portal through Computax (or directly, as per office practice) and upload the return
  • After successful upload, download the filing receipt generated by the portal
  • Determine the verification method to be used for this client (Aadhaar OTP, EVC, Digital Signature Certificate (DSC), or physical signature and post to Bengaluru) — check with your senior on the client's preferred/applicable method
  • If the return is e-verified (Aadhaar OTP / EVC) or filed using DSC: download and save the acknowledgement as ITR-Ack - AY-XXYY - ClientName. This document does NOT need to be sent to Bengaluru
  • If the return is NOT e-verified and is to be signed physically and sent to CPC Bengaluru: download and save the form as ITR-V - AY-XXYY - ClientName, get it signed by the client (in original ink signature, blue or black ink as per CPC instructions), and arrange for it to be sent to CPC Bengaluru within the time limit prescribed (generally 30 days from filing — confirm the current applicable limit with your senior, as this can change), by speed post/ordinary post as per current CPC instructions
  • Update the office's return-filing tracker/register with the date of filing, acknowledgement number, verification status, and (if applicable) ITR-V dispatch details
  • Inform the client that the return has been filed and verified, along with the acknowledgement copy, again using only the official communication channel (clause 2.1), with your senior in copy

8PHASE 8: Closing the File / Archival

  • Ensure every document received from the client and every document generated by the firm during the engagement is saved in the current year's client folder, correctly named as per clause 2.2. Nothing should remain only in email/WhatsApp/personal device
  • Verify the folder contains, at minimum: documents received from client, 26AS/AIS/TIS, Trial Balance/BSPL or Receipts & Payments (if applicable), Computation of Income, filed return copy and ack/ITR-V, and the client's approval confirmation
  • Confirm the 'Z'-prefixed shortcuts to last year's folder and to the Tally data folder (clause 2.3) are correctly in place for next year's reference
  • Update the document received-vs-pending tracker (Phase 3) and the return-filing tracker (Phase 7) to reflect that the matter is closed for the year
  • Hand over/flag the file as 'Completed' to your reporting senior for final sign-off and closure in the office MIS/register

9PHASE 9: Scanning of ITR Set — For Office and For Sharing

The ITR Set shall include signed copies of the following — FOR SHARING:

  • ITR-V / Ack
  • Computation of Income
  • Balance Sheet — with all Annexures
  • Profit and Loss Account — with all Annexures
  • Capital Account

The ITR Set shall include signed copies of the following — FOR OFFICE:

  • ITR-V / Ack
  • Computation of Income
  • Balance Sheet — with all Annexures
  • Profit and Loss Account — with all Annexures
  • Capital Account
  • Detailed Trial Balance in Opening – Transactions – Closing format, expanded in full detail (directly exported from Tally, saved as PDF). This should NOT be included in the "FOR SHARING" set.
  • It is to be printed in 2 sets and the first page stamped with "OFFICE COPY" and "ASSESSEE COPY" rubber stamps available in office
  • The Office copy set needs to be scanned

4. Common Mistakes Freshers Should Avoid

  • Contacting a client from a personal mobile number or personal email ID, even "just once" — this is not permitted under any circumstance (see clause 2.1)
  • Saving received documents directly in a download folder or leaving them in email/WhatsApp without renaming and filing them per the naming protocol — this causes documents to get lost or mixed up between clients
  • Starting the current year's working file from a blank sheet instead of rolling over and renaming last year's folder (clause 2.3)
  • Relying only on Form 26AS and skipping AIS/TIS — leads to missed income items such as interest, dividend, and securities transactions
  • Claiming a deduction or exemption in the computation without a supporting document on file
  • Choosing the accounting route (Tally / Receipts & Payments / direct computation) without checking last year's precedent or without asking the senior in an unclear/new case
  • Filing the return without obtaining the client's explicit confirmation/approval on the final computation
  • Filing the return without the senior's review and sign-off
  • Forgetting to track and complete the ITR-V dispatch to CPC Bengaluru in cases where the return is not e-verified
  • Mixing up ITR-V and ITR-Ack — remember: ITR-V is needed only when the return is NOT e-verified and must be physically signed and posted; ITR-Ack is for e-verified/DSC-filed returns and does not need to be posted
  • Not updating the Assessment Year correctly in the file name (e.g., writing AY-1920 for a return that is actually for AY-2627)

5. When to Escalate to Your Reporting Senior

As a fresher, you are expected to raise the following situations with your reporting senior BEFORE proceeding — do not take an independent call on these:

  • Any new client where no prior-year precedent is available with the firm
  • Any discrepancy between client-provided information and Form 26AS/AIS/TIS that cannot be resolved through a simple clarification from the client
  • Any case involving capital gains on property, unlisted shares, or foreign assets/income
  • Any case where the client has not responded to document requests close to the filing due date
  • Any case involving a pending notice, intimation, demand, or refund adjustment from an earlier year
  • Any uncertainty on which ITR Form, tax regime, or accounting route (Tally vs Receipts & Payments vs direct computation) applies
  • Any instance where you are asked, by anyone, to use a personal number/email to contact a client, or to bypass any step in this SOP
  • Any instances of Balance Sheet not tallying, suspense entries, or negative cash — do NOT forcefully match it
  • Verify unexplained debits and credits to the Capital Account
