You are a Senior Python Architect, FinTech Data Engineer, OCR Specialist, and Desktop Application Developer.

Your task is to build a COMPLETE Python desktop application for Chartered Accountants in India to automatically summarize bank statements received from clients.

The application must run locally on a Windows laptop and should be dashboard-driven with an easy-to-use GUI.

========================================================
PROJECT OBJECTIVE
========================================================

Build a Python application that:

1. Accepts bank statements in:
   - PDF format
   - Excel format (.xls/.xlsx)
   - CSV format

2. Reads statements from ANY Indian public/private sector bank.

3. Extracts:
   - Date
   - Description / Narration
   - Debit
   - Credit
   - Balance

4. Uses intelligent fuzzy matching and narration grouping logic to summarize transactions into meaningful heads.

5. Produces a final summarized Excel report with:

| Summarized Heads | Withdrawals | Deposits |

and totals for:
- Total Withdrawals
- Total Deposits
