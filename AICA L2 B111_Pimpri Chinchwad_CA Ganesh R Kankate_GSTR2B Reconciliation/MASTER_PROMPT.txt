2. STAGE 1 – TALLY PURCHASE REGISTER STANDARDISATION
==================================================================
2.1 Header row: scan the first 80 rows; the header is the first row that contains both "Date" and "Particulars". If not found, raise a clear error. Make duplicate header names unique; blank headers become Column_1, Column_2...

2.2 Identify columns by name:

2.4 Every other column: if at least 80% of its non-blank values are numbers, it is a LEDGER (amount) column, otherwise a text column (e.g. Narration) that is carried through as-is.

2.5 LEDGER CLASSIFICATION (most important – this was the IGST bug). Check in this order:
  a) "Gross Total" -> gross
  b) value / quantity / qty / rate / alt units / billed qty / actual qty -> info only (not summed)
  c) TDS or "Tax Deducted" (whole word) -> TDS
  d) TCS or "Tax Collected" -> other
  e) Round Off / Rounded Off / Rounding -> other
  f) Decide whether it is a PURCHASE/EXPENSE ledger:
     PURCHASE WORDS (regex, case-insensitive): pu+r (covers Pur, Purchase, Purchases, Puurchases), labour/labor, charge, expense, exp/exps, service, job work, freight, cartage, material, consumable, stores, spares, repair, maintenance, rent, hire, fees, commission, goods, inward, interstate/inter state, intrastate/intra state, local, import, stock, asset, machinery, equipment, packing, transport, contract.
     TAX-LEDGER WORDS (these WIN over purchase words): input, ITC, payable, receivable, output, credit ledger, RCM, reverse charge.
     is_purchase = (has a purchase word) AND (has NO tax-ledger word).
  g) If NOT is_purchase:
       Cess -> other
       IGST or "Integrated Tax" -> IGST
       CGST or "Central Tax" -> CGST
       SGST / UTGST / "State Tax" / "UT Tax" -> SGST
  h) SEZ (whole word) -> SEZ
  i) everything else -> TAXABLE
  Match GST words as whole words (e.g. regex (?<![a-z])igst(?![a-z])).
  Required results:
    "Purchase IGST 18%", "Purchases IGST", "IGST Purchases", "IGST puurchases", "Purchase - Interstate (IGST)", "Labour Charges IGST", "Job Work IGST 18%", "Pur IGST 28%", "Purchase 18%", "Purchase Local CGST SGST"  -> TAXABLE
    "Input IGST", "IGST Input", "Input IGST 18%", "IGST @18%", "IGST", "Input IGST on Purchases", "IGST RCM Payable" -> IGST
    "Input CGST 9% Local", "CGST Input 2.5%" -> CGST ;  "Input SGST" -> SGST
    "TDS on Labour Charges 194C" -> TDS ;  "Round Off" -> other

2.6 Standard columns (row-wise sums of the classified ledgers):
- Taxable = sum of TAXABLE ledgers
- IGST, CGST, SGST = sum of their ledgers
- SEZ SALES = sum of SEZ ledgers, 0 if none
- TDS = -(absolute sum of TDS ledgers)  (always shown negative; add +0.0 so -0.0 shows as 0.0)
- Diff = Gross Total − (Taxable + IGST + CGST + SGST + SEZ SALES + TDS), rounded to 2 decimals
- Cess / TCS / Round Off = sum of "other" ledgers (explains any Diff)
- Books Invoice Value = Gross Total − TDS  (TDS added back, so it compares with the 2B invoice value)

2.7 GST RATE VERIFICATION (extra check):
- GST Rate % = (IGST + CGST + SGST) ÷ Taxable × 100, rounded to 2 decimals.
- GST Rate Check (text):
   * Taxable = 0 and tax = 0 -> "No Tax"
   * Taxable = 0 but tax > 0 -> "CHECK - Taxable is 0 but tax booked"
   * tax = 0 -> "No GST (0%)"
   * IGST and CGST/SGST both booked -> "CHECK - both IGST and CGST/SGST booked"
   * CGST ≠ SGST (beyond tolerance) -> "CHECK - CGST and SGST differ"
   * nearest standard slab from (0.1, 0.25, 1.5, 3, 5, 6, 12, 18, 28, 40): if |rate − slab| ≤ 0.1 or |tax − Taxable×slab/100| ≤ ₹ tolerance -> "OK - 18%" (show the slab)
   * otherwise -> "CHECK - not a standard GST rate (mixed rates / wrong ledger?)"
