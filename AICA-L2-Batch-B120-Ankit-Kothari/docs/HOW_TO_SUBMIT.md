# How to submit Saathi (about 45 minutes)

## 1. Check it works (2 min)
Unzip, open the `web` folder, double-click `index.html`. Fill in the welcome form (name, city, birth date, 18+), then try each tab.

## 2. Put it online (3 min, free, optional but nice for the form and video)
Go to **app.netlify.com/drop**, sign in with Google and drag the **`web` folder** onto the page. You get an `https://….netlify.app` link. To keep the link, you must sign in; anonymous drops expire.

## 3. Upload to the course GitHub (10 min, web browser only)
1. Rename the unzipped folder to **`AICA-L2-Batch-B120-Ankit-Kothari`**. Edit `README.md` line 3 to add your batch number.
2. Open **github.com/aiinicai/AICA-Level-2-Projects** → **Fork** → **Create fork**.
3. In **your fork**: **Add file → Upload files** → drag the **whole renamed folder** (not the files inside it) onto the page. It has 74 files, under GitHub's 100-file limit, and the APK is under 25 MB.
4. Commit message: `Add AICA Level 2 Project - Ankit Kothari - Saathi`. Keep "Commit directly to main" → **Commit changes**.
5. On your fork's main page: **Contribute → Open pull request**. Check the base is `aiinicai/AICA-Level-2-Projects` `main`. Title: `Add AICA Level 2 Project - Ankit Kothari`, paste the description from section 5 → **Create pull request**.
6. Your **GitHub project URL** for the form:
   `https://github.com/<your-username>/AICA-Level-2-Projects/tree/main/AICA-L2-Batch-B120-Ankit-Kothari`

## 5. Google Form answers

**Title:** Saathi: AI-built daily companion for body, glow and stars

**Description:**
Saathi is a private, honest daily companion that brings wellness, beauty and astrology into one app, as a web app that works on any phone or computer plus a native Android app. It needs no account, server or API key, and personal data stays on the device. Features: a daily fortune cookie; a day card with real astronomy for the user's city (Moon sign Vedic/Western, nakshatra, tithi, Rahu Kaal and Abhijit from actual sunrise); numerology (Life Path with master numbers, Moolank, Bhagyank, Lo Shu grid); a signature studio that measures slant, baseline and size from the user's strokes; BMI with WHO and Asian cut-offs; walk, water and eye/neck routines with points and streaks; a 10-question Big Five (TIPI) test; and skin, hair and nail rituals.
AI approach: built with Google AI Studio (Gemini) and Claude using a specify → generate → review → test loop. Placeholder outputs from the first version were replaced with grounded calculations verified against a professional astronomy library (Moon within 0.02°, sunrise within 3 minutes) and worked numerology examples. Responsible-AI choices: 18+ confirmation, no medical claims, BMI never from photos, signatures never stored, and on-device privacy. Quality: 10 automated accuracy tests and an 11-step browser test, all passing.
