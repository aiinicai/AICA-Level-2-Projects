# Example outputs

Documents generated by the application from **Case 9 — Leaving s. 44AD after an earlier opt-in**,
one of the twelve synthetic sample cases.

**All figures and names are invented. No client data appears in these files.**

| File | What it is |
| --- | --- |
| `01_Detailed_Working_Paper_Case09.pdf` | The full working paper, 7 pages — cover, all ten sections, reasoning chain, statutory references, review points, sign-off |
| `02_Executive_OnePage_Case09.pdf` | The one-page summary for a client or partner |
| `03_Working_Paper_Word_Case09.doc` | The Word version — A4 page setup, running header, footer with page numbers, numbered sections, tables, sign-off block |
| `04_Calculation_Audit_Trail_Case09.json` | The structured record of inputs, computed ratios, tests evaluated, rules triggered and result, with a timestamp |

---

## Why Case 9

Turnover is ₹90,00,000 — below the ₹1 crore limit. On a turnover-only reading, no audit.

But s. 44AD was used in an earlier year, profit is now 2.22% — below even the 6% floor of the
deemed income — and total income exceeds the ₹4,00,000 basic exemption. Section 44AD(4)
applies, so audit is required under s. 44AB(e), with no turnover threshold.

## Reproducing these

1. Open `../app/index.html`
2. Overview panel → Sample cases → **Leaving s. 44AD after an earlier opt-in**
3. Working Paper panel → the three document buttons
4. Review & Export panel → Download audit trail (JSON)

For the PDFs, choose **A4, portrait, background graphics on** in the print dialogue.
