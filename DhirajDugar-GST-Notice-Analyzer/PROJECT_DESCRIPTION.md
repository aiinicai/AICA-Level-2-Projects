## Project title

GST Notice Analyzer: Offline AI-Assisted Review and Reply Drafting

## Project description

GST Notice Analyzer is a local Streamlit application that assists a Chartered Accountant's first review of GST notices. It accepts searchable PDF or text input, recognises ASMT-10, DRC-01 and DRC-01A headings, extracts explicitly labelled metadata and identifies five supported issue categories: ITC mismatch, output-liability differences, reverse charge, blocked credit and delayed/non-filing.

The project combines evidence-backed rules with a local TF-IDF and logistic-regression classifier trained on synthetic labelled examples. Model suggestions require human confirmation; legal provision notes and reply structures are curated templates. The app provides source extracts with page references, facts-to-confirm lists, document checklists, editable working reply skeletons in Word/Markdown, and an analysis audit export.

Three fictional sample notices and an automated test suite support demonstration and verification. No API key or external model is required. The tool does not decide liability, compute statutory deadlines, update law automatically or file a reply. All facts, provisions and conclusions require professional review.
