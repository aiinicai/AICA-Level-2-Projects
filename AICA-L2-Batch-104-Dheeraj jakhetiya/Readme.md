# 🛒 Smart Kirana Stores
### AICA Level 2 – Batch 104 Dheeraj Jakhetiya

## 📌 Project Overview

**Smart Kirana Stores** is a Python-based desktop application designed to simplify and automate day-to-day operations of a Kirana (grocery) store.

The application provides an easy-to-use interface for managing store-related activities and maintaining data digitally.

This project was developed as part of the **AICA Level 2 – Batch 104** project.

---

## 🎯 Project Objectives

The main objectives of this project are:

- 🏪 Digitize Kirana store operations
- 📦 Simplify inventory and product management
- 💾 Store information using a local database
- ⚡ Reduce manual data entry
- 🖥️ Provide an easy-to-use desktop application
- 📊 Improve accessibility and organization of store data

---

## ✨ Key Features

- 🛒 Smart Kirana store management
- 📦 Product and inventory management
- 💾 SQLite database integration
- 🔍 Easy data access and management
- 🖥️ User-friendly desktop interface
- 📁 Local data storage
- ⚡ Standalone Windows executable available
