# Capstone presentation and demonstration

## Suggested slides

1. Problem: fragmented economic, corporate and regulatory information.
2. Scope: one Windows application, shared event model and offline history.
3. Source feasibility: official RSS, licensed calendar adapter and authorized imports; distinguish tested connections from external dependencies.
4. Architecture: adapters, validation, SQLite revisions, shared queries and persistent notification jobs.
5. Data integrity: unknown values, date precision, provenance, conservative deduplication and correction history.
6. Product demonstration: navy dashboard, calendar views, filters, detail pages and charts.
7. Automation: refresh intervals, initial-sync suppression, watchlists, configurable reminders and native notifications.
8. Validation: automated tests, real RSS outcomes, packaged executable and remaining deployment checks.
9. Limitations and commercial readiness: rights, coverage, signing, clean-machine testing and monitoring while running.
10. Future roadmap: the user's Phase 2–4 scope, explicitly outside this build.

## Eight-minute demonstration

- Minute 0–1: launch the EXE without Python; explain the SAMPLE banner.
- Minute 1–2: switch agenda/week/month; filter corporate and regulatory records.
- Minute 2–3: open CPI; show readings, definition, chart, source and revisions.
- Minute 3–4: change Asia/Kolkata to America/New_York; discuss date-only records and DST.
- Minute 4–5: import the bundled synthetic CSV again; show stable record count and ingestion log.
- Minute 5–6: create/edit a notification rule; show watchlist, country and custom intervals.
- Minute 6–7: simulate a reminder, inspect notification history and click the toast if Windows displays it.
- Minute 7–8: show source health and the dated integration report, then explain licensing and runtime limits.

## Course mapping

Day 1: source connectors, scheduled monitoring and deterministic event handling. Day 2: API authentication and structured validation; AI explanations are deliberately unnecessary for this release. Day 3: Python, pandas, SQLite, PySide6 and PyInstaller. Day 4: modular architecture, relational history, UI and deployment. Day 5: ingestion triggers, persistent reminder scheduling, retries and duplicate prevention. No external automation platform is required merely to demonstrate a course topic.
