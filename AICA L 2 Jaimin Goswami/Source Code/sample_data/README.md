# Sample provenance

Every bundled event is synthetic, generated by `app/services/demo.py`. Company names, values, schedules and disclosures are fictional examples, not market data. All records carry `sample=true`; the UI and alerts display SAMPLE. Real official URLs in educational definitions identify reference publishers, not evidence for synthetic readings.

The CSV and JSON contain the same demonstration schema. The app generates relative dates on first launch so historical and future examples remain useful. No restricted dataset or provider credential is bundled.
