PROMPT FILE
=============
This is the original project specification/prompt used to build InsightFlow AI
with an AI coding assistant (Claude).

------------------------------------------------------------------------------

Build a polished MVP web app called **InsightFlow AI — Business Dashboard Generator**.

The app should let a user upload a **CSV or Excel file**, automatically understand the dataset, and generate a professional business analytics dashboard.

### Core flow

**Upload Dataset → Analyze → Generate Dashboard → Show Insights**

### Must-have features

1. **CSV/Excel upload**
   * Also include a **"Try Demo Dataset"** button.
   * Demo dataset should contain around 500 rows of realistic business data.

2. **Automatic column detection**
   * Detect columns dynamically based on names, data types and values.
   * Detect possible: Date, Revenue/Sales, Profit, Quantity, Product, Category, Region, Customer
   * NEVER assume fixed column positions.
   * NEVER use things like `row[5]`.
   * The app must continue working when columns are renamed, reordered, missing, or additional columns are added.

3. **Data validation**
   * Detect missing values, invalid dates and invalid numeric values.
   * Show warnings instead of crashing.
   * One bad row must never break the application.

4. **Automatic KPI cards**
   Dynamically show relevant metrics such as: Total Revenue, Total Profit, Total Orders/Rows, Average Order Value, Quantity.
   Only show a KPI if the required data exists. Never invent data.

5. **Automatic charts**
   Generate charts based on available columns: Revenue over time, Revenue by category, Revenue by region, Top products, Revenue vs profit.
   Only generate meaningful charts when the necessary columns exist.

6. **AI Business Insights**
   Create an insights panel showing things such as: Top-performing category, Best region, Revenue trend, Profit trend, Unusual changes, Important business observations.
   IMPORTANT: Never invent statistics. Insights must come from the actual dataset.
   If no AI API is available, use a local rule/statistics-based insight engine so the app works without an API key.

7. **Anomaly detection**
   Detect unusually high/low values or sudden changes using a simple method such as IQR, z-score or percentage change.

8. **Data Preview**
   Show: Number of rows, Number of columns, Missing values, Detected column types, First 20 rows.

9. **Simple filters**
   Where applicable, allow filtering by: Date, Category, Region, Product.
   Charts and KPIs should update after filtering.

### UI

Make it look like a modern SaaS analytics application, NOT a basic student project.

Use: React + Vite, Tailwind CSS, Recharts, PapaParse for CSV, SheetJS/xlsx for Excel.

Create a clean sidebar:
**InsightFlow AI**
* Dashboard
* Data
* Insights

Dashboard should contain:
**Header**
> Business Performance Dashboard
> Your data, analyzed automatically

Then: **KPI cards → Charts → AI Insights → Anomalies**

### Critical reliability requirement

I previously had problems with spreadsheet columns being incorrectly mapped/highlighted.
Design the data-processing system to prevent this completely.

Use a pipeline:
**Parse → Validate → Detect Columns → Normalize → Calculate Metrics → Generate Charts → Generate Insights**

Keep these stages separate.
Never hard-code assumptions about a specific dataset.

Test the application conceptually with:
**Dataset A:** Date, Product, Category, Region, Sales, Profit
**Dataset B:** Date, Item, Revenue, Location
**Dataset C:** Customer, Product, Amount
**Dataset D:** Missing values + invalid data

The application must not crash on any of them.

### Most important

This is a **1-hour MVP**.
Do NOT add authentication, complicated backend infrastructure, payments, or unnecessary features.

Prioritize:
**Reliability > Dynamic data handling > Dashboard > Insights > UI polish > Extra features**

Build the complete working application and provide all files plus simple commands to install and run it locally.

Before giving me the final answer, check for:
* Missing imports
* Undefined variables
* Broken components
* Incorrect column assumptions
* Runtime errors
* Empty datasets
* Missing/invalid values

FOLLOW-UP PROMPTS
------------------------------------------------------------------------------
After the initial build, the following follow-up requests were used to package
the application for distribution:

1. "can you make it exe?" — clarified to mean a packaged Windows executable
   plus a .bat launcher script.
2. "can u make it for macbook?" — extended the same packaging to a native
   macOS .app bundle (built for both Apple Silicon and Intel).
3. "give me dummy dataset too to analyse" — requested a separate sample CSV,
   with different column names than the built-in demo, to test the column
   auto-detection independently.
