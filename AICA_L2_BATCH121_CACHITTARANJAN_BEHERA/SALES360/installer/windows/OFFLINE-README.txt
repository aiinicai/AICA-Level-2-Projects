SALES360 0.9.0 - Offline Windows x64

Version 9: Statutory Compliance includes UAE VAT calculation linked to issued final invoices, manual eligible input credits and signed adjustments, reviewed VAT201 working papers, the FTA portal link and local filing acknowledgements. Analytics & Reports adds filed VAT period amounts and totals. Five fictional tax invoice PDFs and VAT controls are included under examples. See VAT-RULES-AND-SOURCES.md and the twelve-page guide. Portal filing is manual and needs internet; core computation is offline.

Run the complete installer, or extract the entire portable ZIP and run Start-SALES360.bat. No Python installation, API key or internet is required for the local application. The Python launcher alone is not the complete application.

Version 8: Customers > Import Customer Statement of Accounts, or the dedicated SOA Import menu. Preview one or multiple statement sheets, approve the customer/project plan and financial reconciliation, then import. Missing customers and projects are created automatically. Existing master details are preserved by default; complete missing fields under Customers > View / edit all fields. Review imported projects' real contract fees and previously billed milestones before preparing new certificates. Legacy SOA projects also require this review after upgrading.

Retained installer fix: Browse can select existing empty folders and new destinations. Folder validation ignores dot entries and runs on Next, not inside the Browse dialog. Unrelated, hidden files and subdirectories still prevent installation into an unrecognized nonempty folder.

Previous maintenance: fixes blank-page menu navigation; isolates each menu list; provides a recoverable page error screen. System Administrator can perform all business workflow actions, with approval overrides audited. Existing validation and company isolation remain enforced.

Version 7: first-run company and System Administrator setup, registered recovery email, accounting period dates, Settings USER management for Administrator-created users, Customer Master import and downloadable Excel/SOA formats. Existing data and logins are preserved.

Also retained: Utility, Analytics & Reports, Setting; nine Excel/PDF reports; four themes; change password; Administrator recovery mailbox; Outlook recovery draft helper; safe repair and file integrity checks. See INSTALLATION-AND-USAGE.pdf.

Tally: local read-only company test and basic customer XML export. Real Tally version/ledger/tax acceptance pending; no automatic voucher posting. Zoho: external browser link and file exchange; live OAuth sync is not configured. Outlook: installed client/profile needed; sending requires connectivity and user review. One-use reset links work on the SALES360 PC only.

Repair-SALES360.bat checks libraries and program files; preserve business data. Backup-SALES360.bat requires the app stopped. Local DPAPI backups require the same Windows identity/machine. The installer offers an optional desktop icon at Finish.
