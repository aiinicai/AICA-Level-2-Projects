**Release:** v1.4.0

## Project purpose

This Windows desktop application helps a CA practice organise GST verification client-wise and project-wise. It imports supplier invoice data, validates and deduplicates GSTINs, assists with GST Portal searches, captures GST registration and return-filing details for the selected financial year, saves evidence PDFs, and produces Excel reports.

Portal login, CAPTCHA, MFA and OTP remain user-controlled. After the GST Portal accepts a search, the application automates GSTIN entry, data capture, PDF preservation and movement to the next GSTIN in the queue.

## Run the application

Open `04_Executable` and run `Desi_Fintax_ASG_GSTN_Verifier_Setup_1.4.0.exe` on Windows 10 or Windows 11. Python is not required for normal installation.

No GST Portal password, OTP, CAPTCHA response, API key or client database is included in this submission. Live portal access is subject to the GST Portal's controls and terms. The software does not claim to bypass CAPTCHA or other access safeguards.
