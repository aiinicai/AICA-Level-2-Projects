# Reco-Do sample data

Generated by `npm run samples` (`node scripts/generate-samples/index.mjs`). The generators use a fixed-seed PRNG
(mulberry32) and fixed dates, so every run produces byte-for-byte identical files. After generating, `verify.mjs`
re-reads every file and checks the invariants below (balances, statement identities, planted scenarios, tier counts).
A machine-readable copy of the expectations is in `expected-results.json`.

All companies and people are fictional. Our company is **Desert Pearl Trading LLC**, Dubai. Currency AED. All dates fall in
Aug-Sep 2026. UAE weekend (Saturday/Sunday) is respected for normal bookings.
