# Version floors, not exact pins.
#
# Exact pins look reproducible but they break the moment someone runs this on a
# newer Python than the one it was written on: pip cannot find a matching
# prebuilt wheel, falls back to compiling from source, and then demands a C++
# toolchain. Floors let pip pick the newest release that has a wheel for
# whatever Python is installed.
#
# Everything here is either pure Python or ships prebuilt wheels. Nothing in
# this file needs a compiler.
