\# AssetTrust AI



\## AI-Powered Fixed Asset Governance Control Tower



\*\*AICA Level 2 Capstone Project\*\*  

\*\*Developer:\*\* Anuj Sethi



\## Project Overview



AssetTrust AI is an AI-powered Fixed Asset Governance Control Tower designed to support the end-to-end fixed asset lifecycle.



The platform focuses on strengthening asset governance, improving control visibility, supporting compliance, and providing management insights across the fixed asset lifecycle.



\## Key Objectives



\- Fixed asset lifecycle governance

\- Asset register management

\- Asset-level control and monitoring

\- AI-assisted governance review

\- Audit readiness

\- Asset capitalization review

\- Management analytics and insights



\## Technology Stack



\- Google AI Studio

\- TypeScript

\- Vite

\- Node.js

\- React



\## Project Structure



\- `src/` — Application source code

\- `assets/` — AI Studio project assets

\- `server.ts` — Server-side application

\- `package.json` — Project configuration and dependencies

\- `vite.config.ts` — Vite configuration

\- `metadata.json` — AI Studio project metadata

\- `.env.example` — Example environment configuration



\## Security



Actual environment variables and secrets are excluded from version control.



Do not commit API keys, passwords, tokens, or other confidential credentials.
