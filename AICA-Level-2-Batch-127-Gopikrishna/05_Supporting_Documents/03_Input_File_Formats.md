# Input file formats

_Generated by `python scripts/make_templates.py` from `app/importers/specs.py`. Do not edit by hand._

General rules:
- Upload `.xlsx` or `.csv` only. Macro-enabled files are refused. There is a size limit (`CFF_UPLOAD_MAX_MB`).
- ERP exports can be uploaded as they are. The app finds the header row, even below report title rows, and skips `Total` rows. It recognises the header spellings listed below; any other header goes to the Exceptions screen with a suggested match.
- Amounts are in OMR with up to 3 decimals and entered as positive figures. Direction comes from the source type, or from the Type or Inflow/Outflow column.
- The **key** identifies a row across daily uploads, so your holds, defers and other changes survive a re-upload.

## Customer collections (ERP receivables)

Template: `input_templates/customer_collections.xlsx` | Key: **Invoice No**

- One row per open invoice, as exported from the ERP receivables ageing.
- Unpaid invoices already past due are placed in the current lot.

| Column | Required | Type | Also accepted as header | Notes |
|---|---|---|---|---|
| Invoice No | Yes | Text | invoice number, inv no, invoice, document no, doc no |  |
| Customer | Yes | Text | customer name, party, party name, client |  |
| Project | No | Text | project code, project name, job, job no |  |
| Due Date | Yes | Date | due, due on, maturity date, expected date |  |
| Outstanding Amount | Yes | Amount (OMR, 3 dp) | outstanding, outstanding amt, outstanding omr, balance, balance due, amount due, os amount |  |
| Category | No | Text | category name, cash flow category, cf category | Optional. Overrides the default category for this source. |
| Risk Adjusted | No | Y or N | risk, doubtful, risk flag | Y = excluded when the Risk-adjusted scenario is on. |
| Bill Discounted | No | Y or N | discounted, bd | Y = already financed by the bank; not counted again as a collection. |

## Other and recurring items (template)

Template: `input_templates/other_recurring.xlsx` | Key: **Reference**

- Two layouts are accepted:
- 1) LONG: one row per item with a Category column and an Amount column.
- 2) WIDE: Date, Description, then one column per category (the header IS the category).
- Unknown category names or headers go to the Exceptions screen to be mapped.

| Column | Required | Type | Also accepted as header | Notes |
|---|---|---|---|---|
| Reference | No | Text | ref, id |  |
| Category | No | Text | category name, cash flow category |  |
| Description | Yes | Text | details, narration, item, particulars |  |
| Date | Yes | Date | due date, payment date, expected date |  |
| Amount | No | Amount (OMR, 3 dp) | amount omr, value |  |
| Inflow/Outflow | No | Inflow or Outflow | direction, in out, type, flow | Inflow or Outflow. If blank, the category's direction is used. |
