# AICA Level 2 Capstone: Cash Flow Forecast (OMR, 10-day lots)

A local web app that replaces a finance team's manual daily Excel cash-flow review: it imports ERP and bank
files, forecasts working capital in 10-day lots, lets users hold cheques and adjust items on screen, and exports
Excel with live formulas that are checked by LibreOffice before release. Built with Claude Code from a single
master prompt, phase by phase. All data is synthetic.

| Folder | Contents |
|---|---|
| `01_Project_Summary_Document/` | Project summary (Word and PDF) |
| `02_Prompt_Files/` | The master prompt and the log of every follow-up prompt |
| `03_Example_Files/` | Synthetic input files and a checked Excel export |
| `04_Executable_Files/` | Complete source code with start scripts and `HOW_TO_RUN.md` |
| `05_Supporting_Documents/` | Admin/IT guide, user manual, input formats, layout notes, input templates, test results |
