BRMCo ACCOUNTING HUB - HOW TO RUN
=================================

This application is deliberately NOT a single .exe file. It is two source-code
projects that run with Python, which is safer, easier to inspect and easier to
extend. The executable files are the one-click launchers:

  brmco-accounting-local\start_local.bat     <- the main application (run this)
  brmco-accounting-server\start_server.bat   <- optional central server (Phase 1: health/version only)


REQUIREMENTS
------------
- Windows 10 or 11
- Python 3.12 from https://www.python.org
  (during installation, tick "Add python.exe to PATH")
- Internet access on first run only (to download the Python libraries)
- TallyPrime, only for posting real entries. Demo Mode works without Tally.


STEPS
-----
1. Extract this ZIP to a short path, e.g. C:\BRMCo
   (very long folder paths can cause problems on Windows).

2. Double-click  brmco-accounting-local\start_local.bat
   - First run: it sets up everything automatically (about 1-2 minutes).
   - A black window stays open. Keep it open while using the app.
   - The browser opens http://127.0.0.1:8000 automatically.
     Do NOT open frontend\index.html directly; it only works through the address above.

3. Try it in DEMO MODE (the default; nothing is posted to Tally):
   Sales -> "Download filled sample" -> "Upload & Validate" -> Preview -> "Confirm & Post".

4. To connect to real TallyPrime:
   a) TallyPrime: F1 Help > Settings > Connectivity > Client/Server configuration:
      TallyPrime acts as = Both, Enable ODBC = Yes, Port = 9000. Restart Tally.
   b) App: Settings -> fill in the company details, untick "Demo mode", Save.
   c) App: Tally > Connection > "Test Tally Connection".
   d) App: Tally > Master Sync > "Sync all masters from Tally".
   Note: TallyPrime in EDUCATIONAL mode only accepts dates on the 1st, 2nd or 31st;
   the app warns about this.

5. To stop, close the black window.


MANUAL COMMANDS (for technical users)
-------------------------------------
  cd brmco-accounting-local
  python -m venv .venv
  .venv\Scripts\activate
  pip install -r requirements.txt
  uvicorn app.main:app --host 127.0.0.1 --port 8000

  Run the automated tests:   pytest -q
