HOW TO RUN - greytHR Payroll Reconciliation (version 2.1)

FIRST TIME ONLY
1. Install Python 3.10 or newer from https://www.python.org/downloads/
   During installation tick "Add python.exe to PATH".
2. Unzip this folder anywhere (for example Documents\Payroll Reco). Spaces in the path are fine.

EVERY TIME
1. Double-click "Run Payroll Reco.bat".
   The first run installs the required packages (needs internet, a few minutes).
2. Your browser opens the app. Choose (or type) the client name.
   For each month, either upload the greytHR Salary Statement (.xls, .xlsx or .csv) or click
   the "Saved" button next to it and pick a register you used before. Check the month labels.
3. Click "Run Reconciliation". The screen shows FULLY RECONCILED or NOT FULLY RECONCILED.
4. Click "Download reconciliation workbook (.xlsx)". In Excel, click "Enable Editing" if asked,
   so the formulas calculate. The first sheet, Dashboard, is the one-page view for management.

SAVED REGISTERS
- Uploaded registers are saved automatically when you run a reconciliation (untick the box to skip).
- They are kept in the "Payroll Register Library" folder next to app.py, one sub-folder per client.
  This folder holds salary data: keep it on a secure drive and include it in your backups.
- To remove one, open "Manage saved registers" at the bottom of the screen.
5. Close the black window to stop the app.

IF SOMETHING GOES WRONG
- The black window stays open and shows the reason. Common causes: Python not installed or not
  on PATH; no internet on the first run; a file uploaded that is not a greytHR salary statement.

OPTIONAL - RE-RUN THE AUTOMATED TESTS
  Copy the two salary statements into tests\data with their original names, then in this folder run:
      py -m pip install pytest
      py -m pytest -v tests
