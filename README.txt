CBSE Exam Generator Version 1

1) Streamlit browser app:
   pip install -r requirements.txt
   streamlit run cbse_exam_generator_streamlit.py

2) Desktop Tkinter app:
   pip install -r requirements.txt
   python cbse_exam_generator_desktop.py

Windows note: Tkinter is normally included with standard Python for Windows.

The sample database contains Grade 10 Mathematics, Science and Social Science,
three chapters per subject. Official NCERT textbook links are included in the apps.
