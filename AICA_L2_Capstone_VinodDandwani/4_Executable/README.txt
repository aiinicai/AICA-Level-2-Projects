Bank Statement Analyser PRO - by CA Vinod H Dandwani
HOW TO RUN
1. Open bank_analyser.html in Google Chrome or Microsoft Edge (double-click the file).
2. Internet is needed (the PDF, Excel, chart and OCR libraries load from public servers).
3. Select one or more statement files (PDF / scanned PDF / Excel / CSV / JPG / PNG).
4. Confirm the details on the validation screen, choose account type, enter proposed EMI.
5. Click Confirm & Analyse, then Download Excel workbook.
No API key, no cost, no data leaves the browser.
