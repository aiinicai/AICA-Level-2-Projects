# TDS & TCS Certificate PDF Auto-Renamer

A high-performance, production-ready desktop application and batch processing engine designed for **Indian Chartered Accountants, tax consultants, accountants, corporate finance teams, and TDS/TCS compliance professionals**.

Automates the ingestion, classification, metadata extraction, and safe renaming of Indian TDS and TCS certificates generated by TRACES or tax software.

---

## 🚀 Key Features

* **Multi-Act Support**:
  * **Income-tax Act, 1961**: Form 16 (Part A & B), Form 16A, Form 16B, Form 16C, Form 16D, Form 16E, Form 27D.
  * **Income-tax Act, 2025**: Form 130 (Salary), Form 131 (Non-Salary), Form 132 (Property/Specified), Form 133 (TCS).
* **Robust Extraction**:
  * Accurate identification of Deductee / Employee / Collectee / Payee / Transferor names.
  * Extraction of Deductee PAN, Deductor TAN, Financial Year, Assessment Year, Quarter, and Certificate Number.
  * Fallback OCR support for scanned/image-only PDFs.
* **Intelligent Collision Avoidance**:
  * Automatic increment (`Name (1).pdf`, `Name (2).pdf`), smart disambiguation (appending Quarter & PAN), or skip mode.
  * Zero risk of accidental overwriting of existing files.
* **1-Click Undo & Audit History**:
  * Maintains persistent session logs. Revert an entire batch of renamed files in one click.
* **Modern Windows Desktop UI (PyQt6)**:
  * Non-blocking multithreaded processing (`QThread`).
  * Live summary metric cards, filterable & searchable data table with colored Act badges.
  * Embedded high-resolution PDF preview & metadata inspector.
  * Real-time activity log dock with export to Excel (`.xlsx`) and CSV.
* **Command Line Interface (CLI)**:
  * Headless batch execution support for background scripts, automated pipelines, or server tasks.

## 🖥️ Running the Application

### 1. Launch Desktop GUI (Recommended)
Simply run:
```bash
python main.py
```
Or open a folder directly on startup:
```bash
python main.py -i "C:/Path/To/Certificates"
```

#### GUI Workflow:
1. **Browse Folder**: Select the folder containing your certificate PDFs.
2. **Scan & Analyze**: Analyzes all certificates, classifies Acts & Forms, and generates proposed filenames without touching files.
3. **Inspect / Double-Click**: Double-click any row to view the certificate and verify extracted fields.
4. **Execute Renaming**: Commits the rename operation safely.
5. **Undo (if needed)**: Click `Undo Last Batch` to roll back to original filenames.
6. **Export Report**: Click `Export Report...` to save an Excel reconciliation file.

---

### 2. Headless CLI Mode (Command Line)

Run batch operations directly in terminal or scripts:

* **Dry-Run (Simulate proposed names)**:
  ```bash
  python main.py --cli --input "./sample_test_certificates" --dry-run
  ```

* **Rename using Deductee Name (Default)**:
  ```bash
  python main.py --cli --input "./sample_test_certificates" --template "{DeducteeName}"
  ```

* **Rename to Destination Folder with Custom Pattern**:
  ```bash
  python main.py --cli --input "./sample_test_certificates" --output "./renamed" --template "{DeducteeName}_{FormType}_{Quarter}_{FinancialYear}"
  ```

## 🛡️ Safety & Data Protection Guarantee

* **Preserves Original PDF Contents**: The application only renames or copies files; it **never modifies or alters PDF internal contents**.
* **Zero Overwrite Guarantee**: Collision algorithms detect existing files on disk and prior assignments in the batch, appending sequence markers or disambiguators.
* **Persistent Rollback**: Every batch execution creates an atomic audit checkpoint allowing complete restoration.
