# OCR setup (for scanned PDFs and photos)

Digital PDFs (generated by billing software) are read directly and do **not** need OCR.
Scanned PDFs, JPG and PNG files need **Tesseract OCR**, a free offline program.

1. Download the Windows installer from the UB Mannheim build:
   https://github.com/UB-Mannheim/tesseract/wiki (64-bit, latest 5.x).
2. Install with default options (folder `C:\Program Files\Tesseract-OCR`).
3. Restart IPT. The note "Tesseract OCR is not installed" on Invoice Processing disappears.

IPT also finds Tesseract on PATH, or at the path in the environment variable `IPT_TESSERACT`.
Nothing is sent to the internet; OCR runs on this computer.

## Better accuracy on phone photos / poor scans (recommended)

Run `install_ocr_boost.bat` once (needs the `wheels` folder; no internet). It installs OpenCV and numpy,
which IPT uses to clean the background, remove table lines and straighten tilted pages before OCR.
Without them IPT still works with a simpler cleaning, but reads fewer fields.

## OCR engine (v0.6.1): RapidOCR PP-OCRv6

- First-pass OCR now uses **RapidOCR** (the PaddleOCR PP-OCRv6 small detector and recogniser, run as ONNX on the CPU, Apache-2.0, fully offline).
  Tesseract remains as the second pass and as the fallback.
- Models: `ipt\models\ocr\` (about 31 MB). Python packages: `rapidocr`, `onnxruntime`.
- Install without internet: double-click `install_ocr_models.bat` (uses the `wheels` folder). The log is `ocr_models_log.txt`.
- Choose the engine in **Settings & Backup → OCR engine**: Automatic (RapidOCR if installed) or Tesseract only.
- Measured on the 9 Majisa phone-scan bills (7 fields each): RapidOCR pipeline **63/63 correct, 0 wrong**; Tesseract pipeline about 53–59/63.
