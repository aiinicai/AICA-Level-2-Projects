Revenue Audit Toolkit — Web Edition

Upload once, use everywhere — runs entirely in your browser, nothing installed

Scope note: a browser-only reimplementation of 8 procedures from RevenueAuditSuite (Materiality, Analytical Review, Sampling, Risk Scoring, Walkthrough, Unpredictability procedures, and a Findings/Review workflow tracker). All calculation happens on your device — nothing is uploaded anywhere. Data you enter is kept only in this browser tab's memory (and, for the Findings list, in this browser's local storage) — closing the tab clears everything except saved findings.

Analytical Review

Runs directly against the uploaded population (Upload tab). Reproduces five procedures from analytical_review_engine: monthly comparison, year-over-year comparison, customer concentration, new/lost customer analysis, and unusual trend detection (z-score).

Sampling Tool

Uses the population uploaded in the Upload tab (or upload a separate file below if you want to sample a different population than the one used elsewhere). ID/value columns are auto-detected the same way as the Upload tab — synced from there when using the shared population, or freshly detected if you upload a separate file here. Random and MUS use a seeded, reproducible pseudo-random generator (Mulberry32) — the same seed always gives the same sample. High Value is a targeted, non-statistical selection.

Explainable Risk Scoring

Transparent, weighted scoring across 9 factors — not a trained ML model. Every point is traceable to a documented formula. Fields left blank score 0 for that factor with a note that data was unavailable, rather than being guessed.

Walkthrough Planning

Classifies every transaction in the uploaded population against five scenarios — Small/Medium/Large Sale (by value band), New Customer, Foreign Customer — and shows exactly which transactions require which walkthrough, with the specific rule that triggered each match (a transaction can require more than one, e.g. a large sale to a new foreign customer). The highest-value item per category is marked as the recommended representative to actually walk through, but you can see and choose from every qualifying item. Size bands use Performance Materiality (from the Materiality tab) if you've calculated it, otherwise population percentiles.

ISA 240 Unpredictability Procedures

Detects patterns from the uploaded population: weekend sales, round-number invoices, one-time customers, and dormant customers (reactivated after a gap). Midnight transactions and holiday sales run only if you supply the optional data below.

Findings Tracker

Reproduces review_workflow_engine's Open → In Progress → Resolved → Closed state machine: resolving requires Manager (or above) plus a resolution note; closing requires Partner (or EQR). Saved to this browser's local storage, so it survives a page refresh — but is not shared with anyone else and is not backed up anywhere.

Export — Working Paper

Compiles everything calculated in this session (Materiality, Analytical Review, Sampling, Risk Scoring, Walkthrough, Unpredictability, Findings) into a formatted audit working paper. Fill in the engagement details below — they appear on the working paper's title block and sign-off section.

The Excel version uses ExcelJS, loaded from cdnjs when you click the button — it needs an internet connection at that moment (everything else in this tool works fully offline). It produces a real multi-tab .xlsx with navy header rows, gray row banding, colored severity/status cells, currency/percentage number formats, autofilters, and frozen header rows — matching the same visual style as the HTML export and the Python-based workbook generator elsewhere in this project.
