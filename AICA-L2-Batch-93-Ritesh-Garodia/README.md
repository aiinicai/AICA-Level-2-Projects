What this project does

An automated Tax and Labour-Code Compliance Tracker for a Chartered Accountancy team, covering GST, Income Tax, TDS and Labour Code due dates. It tracks every compliance due date in one extensible master tracker, sends automatic 3-stage escalating email reminders (T minus 2, T minus 1, due and daily) via an n8n workflow routed to the user then the supervisor then the HOD, gives each department and the HOD a live Streamlit dashboard, generates a month end PDF report on demand, and compares actual tax paid against the trial balance to flag variances.
