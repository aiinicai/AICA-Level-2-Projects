Cash Runway
Version : 1.8
Built   : 06-Sep-2026

What changed in this version is in CHANGELOG.md.

To run it:  double-click run.bat  (Windows)  or  ./run.sh  (macOS / Linux)
Then open http://localhost:8000 and sign in as
    guru@northwindrobotics.in  /  cashrunway

On a clean install you will be asked whether to load the demonstration
company or set up your own. If you are not asked, an earlier database is
still in backend\data\cashrunway.db — delete it, or use
Setup > Import data > Start again.
