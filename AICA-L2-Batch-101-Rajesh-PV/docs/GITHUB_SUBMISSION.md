# Submitting to aiinicai/AICA-Level-2-Projects

1. Fork https://github.com/aiinicai/AICA-Level-2-Projects.
2. Name your folder in the course format, e.g. `AICA-L2-Batch-<No>-<FirstName>-<Surname>` (confirm the exact format with the course administrator; the repository README shows two formats).
3. Copy this whole `Judgement Insights Analyser` folder inside it. Add `VIDEO_LINK.txt` with the link to your demo video.
4. **Do not upload:** `.env`, any `.db` register file, `register_judgments/`, recipient lists, `email_audit_log.csv`, real judgments containing client names, `__pycache__/`. (`.gitignore` already excludes most of these.)
5. Commit and open a pull request titled `Add AICA Level 2 Project - <Your Name>`. In the description: purpose, main features, technology (front end, back end, database, AI, hosting/distribution), setup steps - you can copy from README sections 2-3.
