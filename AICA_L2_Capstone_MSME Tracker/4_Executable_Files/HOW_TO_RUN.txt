MSME Payables Compliance Tracker - how to run
==============================================
Requirements: Windows/Mac/Linux with Python 3.10 or newer (python.org; on Windows tick "Add Python to PATH").

Windows (easiest)
  1. Open the folder msme_tracker (inside this folder).
  2. Double-click  Start_MSME_Tracker.bat
     - first run installs the required packages (needs internet), then the app opens in your browser.
  3. Close the black window to stop the app.

Any system (terminal)
  cd msme_tracker
  pip install -r requirements.txt
  streamlit run app.py

First use
  1. Sidebar > Add company (e.g. "Demo Company LLP").
  2. Tab 1 - Upload the vendor master: msme_tracker/demo_data/vendor_master.csv
  3. Tab 2 - Upload Bills: demo_data/bills.csv and Payments: demo_data/payments.csv, set as-of date 30-09-2026, FY 2025, click Run.
     (Or choose "Vendor statements / software exports" and upload a file from demo_data/import_samples/.)
  4. Explore tabs 3-6: Dashboard, Section 43B(h), MSME Form 1, MSME Interest. Download Excel outputs from each tab.

Run the automated tests
  cd msme_tracker
  python -m pytest -q          (61 tests)

Where data is stored: msme_tracker/data/ (created on first use) - company profiles, vendor masters and saved runs.
Uploaded bills/payments are processed locally; nothing is sent to any server.
