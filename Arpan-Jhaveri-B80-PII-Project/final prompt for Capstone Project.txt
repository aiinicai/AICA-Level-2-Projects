### 3. INDIA-FIRST DETECTIONENGINE (25+ CATEGORIES + CHECKSUMS)

Implement a six-signal score fusion detection engine (Base Score + Checksum/Validator Bonus + Keyword Context Bonus + Structured Field Bonus - Negative Suppression):

1. PAN (Permanent Account Number):
   - Pattern: [A-Z]+5}[0-9]{4}[A-Z]
   - Validator: 4th character entity validation (P=Person, C=Company, H=HUF, F=Firm, A=AOP, T=Trust, B=BOI, L=Local Authority, J=AJP, G=Govt).
2. Aadhaar Number:
   - Pattern: \b[2-9][0-9]{3}[ -]?[0-9]{4}[ -][0-9]{4}\b
   - Validator: Strict Verhoeff algorithm checksum, first digit 2-9, non-repeating consecutive blocks.
3. GSTIN (Goods and Services Tax ID):
   - Pattern: \b[0-9]{2}[A-Z]{5}[0-9]{4}[A-Z][0-9A-Z]Z0-9A-Z]\b
   - Validator: 2-digit valid State Code (01-38, 97, 99) + embedded PAN validation + Modulo-36 check character.
4. TAN (Tax Deduction and Collection Account Number):
   - Pattern: [A-Z]{4}[0-9]{5}[A-Z] with 3-letter jurisdiction code and 4th letter entity status.
5. CIN (Corporate Identity Number):
   - Pattern: [LU][0-9]{5}[A-Z]{2}[0-9]{4}[A-Z]{3}[0-9]{6} (21 characters) validating Listed/Unlisted flag, industry code, State code, incorporation year, and ownership code (PTC, PLC, etc.).
6. DIN (Director Identification Number): 8 digits with context keywords.
7. Voter ID (EPIC): [A-Z]{3}[0-9]{7} with context keywords.
8. Indian Passport: [A-PR-WYZ][0-9]{7} with passport context keywords.
9. Driving Licence (DL): [A-Z]{2}[0-9]{2}[ -]?(?:19|20)[0-9]{2}[0-9]{7} with State code and year validation.
10. EPFO UAN: 12 digits starting with '1'.
11. ESIC Number: 17 digits.
12. Bank Account Number: 9 to 18 digits with contextual keywords (account, a/c, acct, bank, khata).
13. IFSC Code: [A-Z]{4}0[A-Z0-9]{6} with 5th character strictly '0'.
14. UPI ID / VPA: [A-Za-z0-9._-]{2,49}@[A-Za+z][A-Za-z0-9]{1,29} with payment handles.
15. Credit / Debit Cards: 13-19 digits validated with the Luhn algorithm.
16. Vehicle Registration / RC Number: Indian state format (MH 01 AB 1234) and Bharat Series (22 BH 1234 AA).
17. Phone / Mobile: Indian mobile (+91 [6-9]\d{9}, [6-9]\d{9}) and international E.164 formats.
18. Email Address: RFC 5322 regex.
19. PIN Code: 6 digits starting with 1-9 with geographic/postal context.
20. Dates (DOB / Incorporation): DD/MM/YYYY, DD-MM-YYYY, YYYY-TM-DD with keyword proximity.
21. Person Names: Honorifics (Mr, Mrs, Ms, Shri, Smt, Dr, CA, Adv, etc.) + capitalized words + user dictionary.
22. Entity / Company Names: M/s, Pvt Ltd, Private Limited, Limited, LLP, LLC, Enterprises, etc.
23. Addresses: Flat, Plot, House, Street, Road, Building regex + context patterns.
24. IP Addresses: IPv4 dotted decimal.
25. Negative Left-Context Suppression: Suppress false positives for financial keywords (Invoice No, Bill No, Challan, Section, Receipt, Order No, GSTR, Form No, Notification).
