# Statutory Compliance Tracker

A Streamlit-based 2026 Indian statutory compliance and tax calendar dashboard.

## Coverage
Income Tax, GST, Companies Act and LLP Act.

## Features
Compliance configuration, GST/TDS/Tax Audit applicability, 5-day alerts, timeline and calendar views, search, completed-task tracking, reminder selection, company/LLP due-date logic and Excel checklist export.

## First Time
Double-click `INSTALL_REQUIREMENTS.bat`.

## Run
Double-click `START_TRACKER.bat`.

Or:
`python -m streamlit run Statutory_Compliance_Tracker.py`

## Important
This is a compliance-planning tool. Statutory due dates may change through notifications, extensions, state-specific rules or taxpayer-specific facts. Verify before filing.
