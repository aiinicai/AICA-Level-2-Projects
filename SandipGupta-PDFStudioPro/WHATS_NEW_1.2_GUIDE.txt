PDF Studio Pro 1.2 - the four improved features, in plain steps
================================================================

1. COMPRESS PDF  (Organize > Compress PDF, or the "Make PDF Smaller" tile)
---------------------------------------------------------------------------
Quality levels
  Lossless        Pictures are not touched. Only wasted space is removed. Safe for everything.
  Best quality    Pictures above 300 dpi are reduced to 300 dpi, JPEG quality 92. Looks the same when zoomed in.
  High quality    (default) reduced to 200 dpi, quality 86. Small print stays sharp on screen and paper.
  Balanced        150 dpi, quality 76. Good for e-mail.
  Smallest file   110 dpi, quality 60. For strict upload limits; check small print afterwards.
  Custom          You choose the DPI and JPEG quality.
Fit under N MB    Tick it and type the limit (for example 5 MB for a portal). The program tries the levels from
                  best to smallest and keeps the BEST one that fits. If even the smallest does not fit, it says so.
What is never made worse
  * Text, tables, drawings (they are not pictures).
  * Logos, charts, screenshots (kept lossless), black-and-white scans (re-packed without loss).
  * A picture is replaced only if the new one is clearly smaller.
Quality check     After saving, pages are compared before / after. The result line says for example
                  "excellent - no visible difference". If it says "reduced", pick a higher level.
Nothing is saved if the result is not smaller. Your original is never changed.

2. PDF TO POWERPOINT  (Convert > PDF to PowerPoint)
----------------------------------------------------
  * "Editable slides" (default): click any text in PowerPoint and type. Each paragraph is one text box with its font,
    size, colour, bold and italic. Each picture is a separate picture you can move or delete.
    Lines, table borders and coloured shapes are kept as one background picture, so the slide looks like the page.
  * "Exact picture of each page": the old behaviour.
  * Scanned pages contain no real text. They stay pictures; with Tesseract installed their text is put in the slide
    notes. To get editable text from scans, run OCR (Searchable PDF) first.
  * If a font is not installed on the PC, PowerPoint replaces it and text can shift a little.
  * Hindi / Indic text in some PDFs cannot be read back correctly from the file itself; check those boxes.

3. AI - HOW TO BECOME A "PRIME" USER
-------------------------------------
General user = AI tools dimmed. Prime user = AI tools switched on. There are three ways; all are in
Settings > "AI set-up". Pick one line, follow the steps shown in the box at the bottom, press "Test connection",
then "Save settings".
  A. AI on THIS computer (free, private, no key)
       Install LM Studio (or Ollama) on this PC, load a model, start its local server.
       Settings > AI set-up > "AI on THIS computer with LM Studio" > Test connection > Save.
       You are Prime immediately. Nothing leaves the PC. A PC with a good graphics card is much faster.
  B. Office AI server (one strong PC serves everybody)
       On the server PC: start LM Studio's server, then in PDF Studio Pro open System > "AI Gateway (Administrator)",
       press "Start gateway", then "Add user" for each person with role Prime. A key is shown ONCE - give it to
       that person. Role General = that key gets no AI.
       On each staff PC: Settings > AI set-up > "Office AI server", type http://SERVER-IP:8800/v1, paste the key,
       Test connection (it must say role: PRIME), Save.
  C. Internet AI service (your own API key)
       Settings > AI set-up > OpenAI / Google Gemini / other, paste the API key, type the model name, Test, Save.
       WARNING: the text of the pages you select is sent to that company over the internet. The program asks you to
       confirm. Use it only if your firm's confidentiality rules allow it. These services charge for use.
The bottom-left corner of the window shows "PRIME user" when AI is on.

4. DIGITAL SIGNATURE (DSC)  (Security > Digital Signature (DSC))
-----------------------------------------------------------------
First: install the token's own driver from your certificate provider and plug the token in.
  Way 1 - "USB token through Windows" (try this first)
       Your name appears in the Certificate list (press "Refresh list" if not). Choose the PDF, press "Sign the PDF".
       The token's own PIN window opens. This way needs no driver file.
       NOTE: this way could not be tested by the author on a real token. If it gives an error, use Way 2.
  Way 2 - "USB token / smart card - PKCS#11 driver file"
       Press "Find automatically" (or browse to the driver .dll, e.g. eps2003csp11.dll, SignatureP11.dll, eTPKCS11.dll
       in C:\Windows\System32). Type the PIN, press "Token diagnostics": your certificate must be listed with
       "-> will sign with: YOUR NAME". Then press "Sign the PDF".
  Way 3 - "Certificate file (.pfx / .p12)" with its password.
Good to know
  * A wrong PIN twice can LOCK the token. Stop after two failures and call your provider.
  * Tokens with two certificates (signing + encryption): the signing one is chosen automatically.
  * "More PDFs to sign in the same run" signs several files with one PIN entry (use a preset position).
  * The signed copy is name_signed.pdf and is checked straight after signing ("content intact").
  * "certificate trusted by this PC: not verified" is normal: this program checks that the file is intact; Adobe Reader
    checks the trust chain (CCA India root). Open one signed test file in Adobe Reader before you rely on it.
  * Never edit, compress or re-save a signed PDF - that breaks the signature. Sign LAST.
