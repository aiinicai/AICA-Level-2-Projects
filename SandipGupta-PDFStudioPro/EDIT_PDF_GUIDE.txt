EDIT PDF - quick guide  (Edit > Edit PDF)
=========================================
Choose a PDF (it opens in the editor). Everything you do is one undoable step (Ctrl+Z / Ctrl+Y or the Undo / Redo buttons).
Nothing touches your original: press "Save edited PDF" and a NEW file  name_edited.pdf  is written to the output folder.
You can keep editing and save again.

TOOLS (row of buttons)
  Select   Click text, a picture, an annotation or a link. Double-click (or Enter) on text to change it: a window opens with the
           words and the font / size / colour / bold / italic / alignment. "Delete this text" removes it. Drag text or a picture to
           move it. Drag a corner of a picture to resize it. Delete key removes the selected item.
           "What a click selects": a LINE (exact spot, one line) or a PARAGRAPH (the block re-wraps inside the same box, use this to
           write several lines or to fix Indian-script text).
  Text     Drag a box (or click) and type: new text with the style chosen below the buttons (Hindi, Marathi, Rs sign all work).
  Image    Drag a box and pick a picture file.
  Rect / Oval / Line / Arrow   Drag on the page. Outline colour, thickness and fill are in the options row.
  White-out  Drag over something to hide it. With the tick ON the text / picture underneath is really deleted (safe for
             confidential data) and the box takes the surrounding background colour; OFF = only covered.
  Link     Drag an area and choose a web address / e-mail or a page in the same PDF.
FIND AND REPLACE (bottom): Find next, Replace this, Replace all; match case, whole word, this page / all pages.
  A uniformly styled line is re-written as a whole so spacing stays natural; lines with mixed styles or table-like gaps are
  replaced word by word. "Keep line width" shrinks a longer replacement (to 60% at most) instead of letting it run on.

GOOD TO KNOW
  * The PDF format has no "paragraph" - editing means: remove the old characters, write the new ones in the same place. The program
    reuses the original font when the file contains it with all the letters needed; otherwise it uses the nearest standard font and
    tells you in the status line ("Font used: ..."). Expect small look differences, especially in bold/italic with unusual fonts.
  * Scanned pages have no real text - run OCR first, or use White-out + Text.
  * Hindi / Marathi / other Indian scripts: NEW text is written with proper shaping (needs Nirmala UI on Windows, or Noto fonts in the
    "fonts" folder). Existing Indian-script text in a PDF is often stored as loose glyph pieces, so a click may select only a
    fragment: switch to "by paragraph" and retype the whole block, or use White-out + Text.
  * Password-protected PDFs must be unlocked first (Security > Password). A digitally signed PDF loses its valid signature when edited.
  * Text under a hyperlink keeps the link. Deleting a picture that is also used elsewhere removes it everywhere only when it overlaps
    another picture; the status line says so.
  * Please check the result before sending it on (zoom in, search for the old words) - and keep your original.
