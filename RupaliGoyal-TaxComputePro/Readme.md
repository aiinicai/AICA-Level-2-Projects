# TaxCompute Pro ⚖️
### Direct Tax Computation & CA Advisory Suite (FY 2025-26 & FY 2026-27)

**TaxCompute Pro** is a comprehensive, client-side direct tax computation and advisory engine designed for Indian Chartered Accountants, tax practitioners, and corporate advisors.

---

## ✨ Key Highlights

- **Multi-Assessee Tax Engine**: Seamlessly compute taxes for Individuals, HUFs, Firms, LLPs, and Domestic Companies (Sec 115BAA/115BAB).
- **Old vs. New Regime Comparison**: Instant side-by-side break-even analysis and automated tax-saving recommendations.
- **Comprehensive Head-wise Income**: Supports Salary (HRA/Standard Deduction), House Property, PGBP (Sec 44AD/44ADA presumptive & depreciation), Capital Gains (STCG/LTCG), and Other Sources.
- **Advance Tax & Interest Schedulers**: Integrated Section 234A, 234B, and 234C interest calculations with quarterly advance tax breakdowns.
- **Client Ready Reports & Export**: Generate clean CA client memos, printable computation sheets, and export full JSON / PDF schedules.
- **100% Offline & Private**: Zero server latency—all financial data is processed locally in your browser.

---

## 🚀 Quick Start

1. Double-click `Launch_TaxCompute_Pro.bat` or open `index.html` in any modern web browser.
2. (Optional) Run `Create_Desktop_Shortcut.bat` for one-click desktop access.
3. Select an Assessee category or a sample case preset to start computing immediately.
