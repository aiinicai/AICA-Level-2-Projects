ORIGINAL PROMPT (as given by the user)
======================================

Travel expenses software

Build a simple Travel expenses software App for a multi national company named "ABC Private Limited." Clearly identifying pre travel approval workflow with backend database support for saving user and task details. Create a Login Page for Authorisation so that user needs to enter their email id and password to login to the app. Also add sign up option. The first user to sign in will be admin user by default. The admin shall be able to add employees and also email id of employee. The employee should sign in with the id entered by admin. The employee should be able to see and edit pending approvals. Only admin gets access to entire employee dashboard. Any other email id other than ones added by admin shall not be allowed the signup. Save all details of sign in and sign up in database.

Workflow should be such as follows: Sales person sending pre travel approval from one city to another city, number of days duration, approximately amount to be incurred, flight cost charges, hotel stay charges, food and misc expenses, purpose of the travel. This request should go to first business head, then to Managing Director. Approval from Managing Director, it should go to support person for booking the flight ticket, booking hotel as per matrix of authority such as 5 Star Hotel, 4 Star Hotel, 3 Stat Hotel. After travel is done, employee should able to submit expenses statement with bills to be attached for expenses incurred. After travel bills are submitted, it should go to Business head for approval and then to HR head for final approval. After approval, it should go to accountant for accounting and payment processing.  Travel to be planned well in advance so that flight tickets are cheaper.

Add Visual Dashboard, Employee wise, Destination wise, Airline wise, Analytics, flag exceptions. Add Roles like Managing Director, Business Head, Sales Manager, Accountant, HR Head, Travel assistent, etc in drop down for admin. Also add features which are generally done at corporates for travel booking, submission of expenses, approvals, attachment of bills, with option of adding more features.

Add full Progressive Web App (PWA) install support and functionality so that Chrome or other browsers show the "Install App" option on desktop and "Add to Home Screen" on mobile phones, also add Install Button in Menu bar.

Provide a single ZIP file containing the Project Summary Document, Prompt File(s), Example File(s), Executable File(s), and any Supporting Documents/Data, with all files properly named
