# Build the NCE Tool v2.5 and Tally Extract v1.0

Use this skill when a user (typically an Indian CA) wants offline Python tools that (A) pull two years of trial balances plus Balance Sheet / P&L PDFs from Tally and (B) convert Tally trial balances into the ICAI Non-Corporate-Entity (NCE) illustrative-format Excel, fully formula-linked, with dropdown-driven mapping, checks, signature blocks and a units selector.

A skill reproduces the same features, layout, rules and tests, not byte-identical code. If the user already has the finished NCE_Tool.zip, tell them to share that.

## Inputs to request (attachments)
1. The ICAI NCE illustrative-format Excel ("template"). 2. Two Tally trial balances in the ODBC format (3A), one per year. 3. Tally Balance Sheet and Profit & Loss PDFs of both years (4 PDFs). 4. Optionally a screenshot of a reference Trial Balance mapping sheet. If something is missing, say so and label assumptions. Never invent data.

## Working rules
1. Study ALL attachments first; reply with a short summary (sheets, columns, sign convention, sample rows, PDF layout) and a plan before coding. If the user says "just study", only study.
2. Accuracy before cleverness. Missing data is derived by a stated rule, labelled "derived", and surfaced on the Review sheet.
3. Test everything yourself: run on the samples, recalculate with LibreOffice (`soffice --headless --convert-to xlsx`), show checks pass, and state what you could NOT test (live Tally; GUI windows if tkinter is missing).
4. Generated figures may contain errors, but every figure must be correctable through dropdowns or editable cells.
5. Offline, Windows first (Mac bonus). Libraries: openpyxl, pypdf (fallbacks pdftotext -layout, pdfplumber), pyodbc for Tally Extract. Absolute paths in your scripts.
6. Deliver one folder/zip `NCE_Tool`: nce_tool.py, tally_extract.py, NCE_ICAI_Template.xlsx (cleaned), run_nce_tool.bat/.command, run_tally_extract.bat/.command, README.txt with changelog (v2.1 repair fix + signature blocks; v2.2 Tally Extract; v2.3 class drop-down; v2.4 income mapping; v2.5 units selector). .bat files check Python and pip-install missing libraries (openpyxl pypdf for the NCE tool; openpyxl pyodbc for Tally Extract). Every GUI field has a CLI option. No __pycache__ or settings json in the zip. VERSION constants: NCE Tool 2.5, Tally Extract 1.0.

## The two tools
- Tally Extract: ODBC only. Per year writes `<Client> FY24-25 Trial Balance.xlsx` (sheet Query1 in the user's ODBC layout plus sheet Info) and `<Client> FY24-25 Balance Sheet.pdf` / `... Profit and Loss.pdf`.
- NCE Tool: two trial balances (+ optional PDFs) -> `NCE_<Client>_FY<latest year>.xlsx` in ICAI NCE format. Must accept Tally Extract output, hand-made ODBC files and the older Tally Trial Balance export (group rows + ledger rows with Debit/Credit columns).

## 3. Input formats
### 3A Trial balance (ODBC extract)
Excel > Get Data > ODBC with `SELECT $Name, $Parent, $_PrimaryGroup, $ClosingBalance FROM Ledger WHERE $ClosingBalance != 0`. Headers `$Name,$Parent,$_PrimaryGroup,$ClosingBalance` (with or without $; sheet usually Query1; header row may not be row 1). PRIMARY GROUP = nearest standard (reserved) Tally group above the ledger, not necessarily the top group. Closing balance signed: debit (assets, expenses) NEGATIVE, credit POSITIVE. The extract lacks the Profit & Loss A/c balance, opening stock and the P&L closing-stock credit. Names may have double/trailing spaces, year prefixes, typos ("Staff Salares", "GST Purhcase"), differ between years; the stock ledger name changes between years and its closing balance is the closing stock.
### 3B Tally PDFs
Condensed two-column P&L and Balance Sheet. Parse kind, period (`1-Apr-25 to 31-Mar-26`), entity, address, opening stock, closing stock, sales, purchases, nett profit, balance-sheet total. pypdf text has NO whitespace between label and amount and sometimes spaced letters ("T o t a l"): use `\s*` in regexes, max() for totals, cut entity at "Profit & Loss/Balance Sheet/#"; fallbacks pdftotext -layout then pdfplumber. Company names look like `NAME ( 25-26) (A)` or `NAME -(2024-25)`: strip year and (A) suffixes for display and file names; title-case all-upper names but keep "LLP".
### 3C ICAI template traps
- ~80 broken external links and ~3,700 junk defined names cause Excel's repair prompt and a save prompt on close. FIX: `load_workbook(path, keep_links=False)`, `wb._external_links = []`, delete ALL global defined names, never set fullCalcOnLoad. Verify the saved xlsx has no externalLinks parts.
- Delete the template's "Note" sheet. Keep Balance Sheet, Statement of P&L, Note 1 to 3, Notes to BS 4 to 6 / 7 to 10 / 11 / 12 to 18, Notes to P & L 19 to 26; add Review, Details, Disclosures, Trial Balance, Workings, Lists. Order: Review, Details, Balance Sheet, Statement of P&L, Note 1 to 3, Notes to BS 4 to 6, 7 to 10, 11, 12 to 18, Notes to P & L 19 to 26, Disclosures, Trial Balance, Workings, Lists. Review is active/selected.
- The template Balance Sheet has an empty merged block G1:K4; unmerge before using column H. Merged cells are read-only in openpyxl.

## 4. Tally Extract (ODBC ONLY)
Do NOT implement an XML-export extraction: ledger requests over Tally's XML/HTTP interface timed out on a real company. The only use of Tally's HTTP port (9000) is an optional 30-second "List of Companies" request to fill the company boxes; ignore failure with a note.
### 4.1 Extraction
pyodbc, DSN default TallyODBC64_9000 (editable), the user's exact query. ODBC reads only the company/period OPEN in Tally, so for each year (previous first, then current) show a prompt naming the expected company and period: `Open the previous year in Tally: "X -(2024-25)" (period 1-Apr-24 to 31-Mar-25). In Tally: Alt+F3 / Select Company, choose it, and go to the Gateway of Tally. Then press OK here.` Cancel aborts. Also query `$Name FROM Company` (all rows), the stock ledger `$OpeningBalance` (best effort) and `SELECT $Name, $Parent FROM Group` (best effort; if unavailable synthesise the tree by attaching each unknown parent under the ledger's primary group). Clear errors if pyodbc/DSN is missing (list pyodbc.dataSources()) or nothing returned. SAFEGUARD: if both years return identical (name, closing) data, stop with "Both years returned IDENTICAL data - Tally was still showing the same company when the second year was read. Run again and really switch the company in Tally before pressing OK."
### 4.2 Companies and years
`company_end_year(name)` parses `(2024-25)`, `( 25-26)`, `(2024-2025)` to the end year; `pick_companies(names, end_year)` returns (current, previous). "Connect / list companies" unions ODBC companies and the HTTP list, fills both editable comboboxes, sets the year box to the latest year found, selects current/previous by year in names, and logs it. Blank company box = read name from Tally. File names use clean_entity(company).
### 4.3 Group tree
`Tree` from groups; head(group) = nearest reserved group walking up. Default reserved groups and parents: Sundry Creditors, Duties & Taxes, Provisions -> Current Liabilities; Sundry Debtors, Bank Accounts, Cash-in-Hand, Stock-in-Hand, Deposits (Asset), Loans & Advances (Asset) -> Current Assets; Bank OD A/c, Secured Loans, Unsecured Loans -> Loans (Liability); Reserves & Surplus -> Capital Account; primary groups: Capital Account, Current Assets, Current Liabilities, Fixed Assets, Investments, Loans (Liability), Misc. Expenses (ASSET), Suspense A/c, Branch / Divisions, Sales Accounts, Purchase Accounts, Direct/Indirect Expenses, Direct/Indirect Incomes. Tolerate parent "&#4; Primary", "Primary" or empty (apply default parent for standard groups). Sanitise illegal XML characters (&#4; etc.).
### 4.4 Outputs
- Trial balance workbook: sheet Query1 (header `$Name,$Parent,$_PrimaryGroup,$ClosingBalance`, one row per non-zero ledger, numeric). Sheet Info key/value rows: company (cleaned), address, pan, period_from, period_to (ISO), opening_stock, closing_stock, nett_profit_computed, source, extracted_on, tool. Name `<Client> FY25-26 Trial Balance.xlsx`.
- Closing stock = sum of Stock-in-Hand ledgers (debit). Current-year opening stock = previous year's closing stock (override the ledger's own opening balance; log it). Previous-year opening stock is unknown: log a note (user supplies real P&L PDF or --py-opening-stock to the NCE Tool). Nett profit (computed) = net credit of Sales/Purchase/Direct+Indirect Expenses/Incomes + closing stock - opening stock. Process the previous year first and pass its closing stock on.
- PDFs (ODBC cannot make Tally print): compute with a minimal dependency-free PDF writer (Helvetica, A4 landscape, multi-page) in Tally's condensed T-format. Balance Sheet: Liabilities (Capital Account, Loans (Liability), Current Liabilities, Suspense, Profit & Loss A/c with "Current Period" and "Less: Transferred") vs Assets (Fixed Assets, Investments, Current Assets with Closing Stock first, Misc. Expenses); sub-groups in standard order then ledgers alphabetically; Indian number format 1,23,456.00; both sides equal. P&L in two blocks (trading, profit & loss): opening stock, purchases, direct expenses, closing stock, sales, gross profit, indirect expenses/incomes, nett profit/loss. Footer "Computed by Tally Extract vX from ledger closing balances (condensed Tally layout) - not a Tally print-out." Must parse back with the NCE Tool's PDF parser and reproduce real Tally totals.
### 4.5 GUI (tkinter, 900x780) - exactly these items
1 "How to talk to Tally (Tally must be open with the company loaded)": radio "ODBC (your Excel query; uses the company / year open in Tally; needs pyodbc)" (only method, no XML radio); fields "Tally host / port" (localhost, 9000), "ODBC data source name" (TallyODBC64_9000). 2 "Company and year": button "Connect / list companies"; combobox "Company for the CURRENT year (type or pick)"; combobox "Company for the PREVIOUS year - only if it is a different company in Tally (leave blank if same)"; "Current financial year ENDS in (e.g. 2026 = FY 2025-26)". 3 "Output": folder + Browse (default ~/Documents); checkboxes "Also produce the Balance Sheet and Profit & Loss PDFs", "Open the NCE Tool afterwards with these files" (calls nce_tool.gui(preload=files)), "Save Tally's raw answers for troubleshooting (folder tally_debug)" (log to tally_debug/log.txt, also on error); scrolling log; big button "Extract from Tally". Errors in a dialog AND the log.
CLI: --method odbc --host --port --dsn --list-companies (prints the company open in Tally) --company --company-py --fy -o --no-pdf --debug --nce.

## 5. NCE Tool
### 5.1 Inputs / years
Two trial balances (any order) + 0-4 PDFs + optional fields. Current vs previous year from, in order: Info sheet period, PDF periods, file name (FY25-26, 2025-26, 25-26), closing stock vs PDF closing stock; else assume the second file is current and warn. Read the Info sheet (company, address, pan, period, opening/closing stock); prefer real PDF values; use Info only when PDFs lack them.
### 5.2 Derived entries
Add three grey derived rows per year so the TB nets to nil: (1) Opening stock (P&L PDF, else previous-year closing stock, else Info, else user input, else nil with warning); (2) Profit & Loss A/c (PDF nett profit, else derived); (3) an "Excluded" balancing row for the closing-stock credit. Verify TB nets to nil, Balance Sheet balances, P&L block nil. Log every assumption.
### 5.3 Mapping engine
Rules from head group + parent group + name keywords. Merge ledgers across years: exact name only within the same head group, then fuzzy >= 0.82, then containment pass; never across head groups. Cover partners' capital/current accounts (detect partner names), loans, bank OD, creditors, duties & taxes, outstanding/provisions, fixed assets by class, investments, stock, debtors, cash, bank, FDs ("F.D.", "FDR"), deposits (guarantee/EMD/BG), loans & advances, GST receivable/ITC/refund, TDS, advance tax, prepaid, sales, other income, purchases, direct expenses, employee costs (incl. typo "Salares"), finance costs, depreciation, other expenses, partners' remuneration and interest.
INCOME RULES: SERV regex = service|job work|labour|contract|consult|rental|repair|software|develop|professional|fee(s)|support|maintenance|amc|subscription|licence|hosting|saas|it|export|outsourc|manpower|training|implementation|website|app|design|testing|royalt|commission.
- Sales Accounts: SERV match -> Note 19(b) sale of services key N19-r7, else Note 19(a) products N19-r6.
- Direct/Indirect Incomes: interest -> N20-r15; dividend -> N20-r16; gain on investments -> N20-r17; grant/subsidy -> N19-r8; discount/rebate/round/forex/exchange/sundry balance/written back/misc/rent received/insurance claim/profit on sale/scrap/incentive/refund -> N20-r18; Direct Incomes otherwise -> Note 19 (services unless name says sales/goods/product/material and not SERV); Indirect Incomes with sale(s)/goods/products -> N19-r6; with SERV and not other/misc -> N19-r7; else N20-r18.
Guessed mappings are orange and listed on Review.
### 5.4 Trial Balance control sheet
One row per ledger. A Sl | B Ledger | C Parent Group (dropdown) | D Head Group (dropdown) | E Note No | F Note Label (dropdown, yellow) | G Line Item (cascading dropdown, yellow) | H/I closing balance CY/PY (Cr-Dr) | J Sign | K/L display amounts CY/PY | M Validation | N Key | O Type | P Nature | Q Appears in | R Auto-map basis | S lookup helper | U/V helper columns for units. Header row 4, data from row 5. Statements pull by SUMIFS on column N.
- Note Label list = all ICAI notes; Line Item list = only lines of the chosen label via DV formula `OFFSET(Lists!$B$1,MATCH($F5,Lists!$A$1:$A$N,0)-1,0,COUNTIF(Lists!$A$1:$A$N,$F5),1)` (DV formulas written WITHOUT leading "="). Parent/Head dropdowns from Lists J/K accept free text.
- Lists sheet: A label, B line, C key, D nature, E type, F appears in, G label|line, H note no, I unique labels, J parents, K heads, M:O unit table.
- Validation symbols: OK / label-line mismatch / unusual opposite-side balance / guessed (orange) / derived. Test derived BEFORE abnormal balance. Show Note Label + Line Item text. Autofilter, frozen panes, colour legend.
### 5.5 Statements and notes
Balance Sheet and Statement of P&L in ICAI layout, every cell a formula, CY and PY columns. Notes 1-26 as in the template. Gross presentation (each ledger on its natural side) makes the total larger than Tally's netted total; explain on Review. Workings: A closing stock (derived/override; toggle C12 Y/N), B fixed assets, C partners (ratios, interest, capital introduced; editable), D checks, E Tally PDF cross-check (real PDFs only). Disclosures sheet. Review sheet (read first): live checks - BS balances CY/PY, profit = P&L A/c, closing stock agreement, TB nets to nil, partner ratios 100%, remuneration 100%, PDF nett profit and sales agree, unmapped = 0 - plus assumptions and items still to complete. Details sheet + signature blocks at the bottom of BOTH Balance Sheet (from row 55) and P&L (from row 52): auditor (firm, FRN, CA name, designation, membership no., UDIN), assessee (firm, address, up to 4 signatories with designation), place, date. Auditor details remembered in nce_tool_settings.json next to the script.
### 5.6 Workings B and the editable Class list
Table: title row 16, header row 17, data from row 18: Ledger | Class (Note 11) | Dep. rate (editable) | WDV prior year-end | WDV current year-end | CY additions | CY depreciation | PY dep rate-implied | PY dep allocated | WDV at start of PY | CY deductions | CY dep existing | CY dep new assets; Total row; check rows. Default class from name rules; default rates {Freehold land 0%, Buildings 10%, Plant and Equipment 15%, Office equipment 15%, Furniture & Fixtures 10%, Vehicles 15%, Others 15%}; rate inferred from ledger movement when plausible (2%-60%).
The Class column has a data-validation dropdown whose source is the EDITABLE list Workings O18:O24 (7 slots = the 7 columns of Note 11; O16 title, O17 header "Class list (drop-down source)", yellow cells). Note 11 headings (row 7, C:I) are formulas =Workings!$O$18..$O$24 and all Note 11 SUMIFS criteria reference those cells, so renaming a class renames the columns. O27 (must be 0) counts ledgers whose class is not in the list; O28 explains "re-pick the new name after renaming". Max 7 classes. Class change does not change the depreciation rate.
### 5.7 GUI and CLI
tkinter: pick two TB files, up to four PDFs, assessee fields (entity, address, PAN, nature), signatories text box ("Name, Designation" per line), auditor fields (remembered), place, date, previous-year opening stock, Generate -> save dialog with suggested name -> log -> success box. gui(preload=files) pre-fills lists. CLI: --entity --pan --nature --py-opening-stock --address --signer (repeat) --aud-firm --aud-frn --aud-name --aud-desig --aud-mno --udin --place --date -o --units.
### 5.8 UNITS SELECTOR (exact design)
One dropdown: Actuals / Hundreds / Thousands / Lakhs / Crores.
- Selector `'Balance Sheet'!H3` (yellow, bold, blue, centred, medium border, DV list "Actuals,Hundreds,Thousands,Lakhs,Crores"); H2 label "SHOW ALL FIGURES IN  (drop-down)"; H4 divisor `=IFERROR(INDEX(Lists!$N$2:$N$6,MATCH($H$3,Lists!$M$2:$M$6,0)),1)`; H5 label `=IFERROR(INDEX(Lists!$O$2:$O$6,MATCH($H$3,Lists!$M$2:$M$6,0)),"Rs.")`; H6 grey help text; column H width 34 (outside print area A:F; unmerge G1:K4 first). Unit table Lists!M1:O6 (Unit / Divisor / Label): Actuals 1 "Rs."; Hundreds 100 "Rs. Hundreds"; Thousands 1000 "Rs. Thousands"; Lakhs 100000 "Rs. Lakhs"; Crores 10000000 "Rs. Crores". Default Actuals (CLI --units).
- Scale where amounts LEAVE the Trial Balance/Workings, never twice. Trial Balance helper columns U `=IF(ISNUMBER(K5),K5/'Balance Sheet'!$H$4,0)` and V (same for L), same number formats, grey font, rows 5 to last+60. In the display sheets (Balance Sheet, Statement of P&L, Note 1 to 3, Notes to BS 4 to 6, 7 to 10, 11, 12 to 18, Notes to P & L 19 to 26, Disclosures) rewrite formulas: (a) `'Trial Balance'!$K$a:$K$b` -> `$U$a:$U$b`, `$L` -> `$V`; (b) every SUMIFS whose sum range is a Workings amount column (D-M of the fixed-asset table) -> `(SUMIFS(...)/'Balance Sheet'!$H$4)`; (c) single-cell references to Workings amount cells (number format contains #,##0 and the cell is not plain text such as the Y/N toggle; e.g. closing stock C10/D10, opening stock C11/D11, D6, partner capital table) -> `(Workings!X/'Balance Sheet'!$H$4)`; ratios, toggles, class names and criteria ranges are NOT scaled; (d) the balance test `ABS(D24-D46)<0.01` -> `<0.01/'Balance Sheet'!$H$4`.
- Workings and Review formulas that read the statements are multiplied back, e.g. `('Balance Sheet'!D24*'Balance Sheet'!$H$4)`, so checks stay in rupees.
- Every "(Amount in Rs.)" heading becomes `="(Amount in "&'Balance Sheet'!$H$5&")"`; "Total capital of the firm (Amount in  Rs.)" likewise (prefix text kept). Non-zero typed amounts in display sheets are not rescaled: log a warning; user adjustments belong in rupees in Workings/Disclosures. Totals use unrounded values (displayed lines may differ from totals by rounding); say so in README.

## 6. What a trial balance cannot tell (label assumptions)
Original cost of fixed assets (Note 11 at WDV), partners' profit-sharing ratio / remuneration (equal by default), MSME split, debtor ageing, long/short-term split of loans and deposits, related parties, contingent liabilities (Disclosures sheet).

## 7. Known pitfalls
Excel repair prompt (links/names). Apostrophes inside single-quoted strings in sheet text: use double quotes. Merging ledgers across head groups gave a wrong PY profit. pypdf text has no spaces. Typos/odd ledgers ("Staff Salares", "GST Purhcase", "Bank Guarantee", "ICICI F.D.") need explicit rules. Derived row flagged "!" when the abnormal-balance test ran first. XML ledger requests time out on real Tally: ODBC only. Tally's Primary is `&#4; Primary`. ODBC reads only the OPEN company: prompt per year and keep the identical-data safeguard. openpyxl workbooks have no cached values: verify with LibreOffice. Merged cells are read-only. Sandbox may lack tkinter: test logic by CLI and say the GUI window was not run. The openpyxl "Print area cannot be set" warning is harmless.
