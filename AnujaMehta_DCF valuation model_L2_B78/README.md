
An interactive web-based financial analytics application built using Python (Streamlit and Pandas) designed to automate corporate equity valuation through the Discounted Cash Flow (DCF) methodology. Tailored for financial professionals, the tool bridges quantitative financial modeling with automated AI reporting.

Key Features & Capabilities:

Intrinsic Valuation Engine: Computes Implied Enterprise Value and Per-Share Equity Value using multi-year Free Cash Flow projections and the Gordon Growth Model.

Dynamic 2D Sensitivity Matrix: Automatically generates a granular sensitivity table evaluating share price variance across shifting WACC (Discount Rate) and Terminal Growth Rate bands.

Customizable Parameters: Allows real-time adjustment of capital structure variables, current share prices, discount rates, and operational growth forecasts.

Instant Excel Reporting: Packages the complete valuation summary and multi-variable sensitivity matrix into a structured, downloadable .xlsx workbook.

AI-Driven Executive Insights: Synthesizes model outputs to generate automated, investment committee-ready commentary on valuation gaps and risk bands.
