# Strategic Advisory Mandate Letter

Produces a Sample Advisory "Scope of Work Mandate" for a new Strategic
Advisory and Growth Partner retainer client, in the exact layout, letterhead and
clause structure of the approved **Example Industries Private Limited (JR
Mart)** mandate dated 16th September 2026. That mandate replaced the earlier
ABCom template; do not fall back to ABCom wording (rolling monthly term,
Transition Assistance, Non Circumvention section, reference numbers), since
those clauses no longer exist in the approved format.

Output is always **both** a `.docx` and a matching `.pdf`, named
`<Client Short Name>_Mandate_Letter.docx` / `.pdf`.

## What this skill covers

One engagement type only: the **exclusive, retainer based Strategic Advisory and
Growth Partner mandate** covering business advisory, fund raising and IPO
readiness. Forensic review mandates, transaction advisory mandates and any other
engagement type need their own template and are out of scope.

## Document structure (fixed)

Cover page (Advisor, Client, Nature of Engagement, Billing Cycle, Fee, Date),
then: 1 Preamble, 2 Background and Objective, 3 Scope of Services (six navy
pillar bars A to F plus SEBI disclaimer), 4 Strategic Approach (four numbered
stage boxes), 5 Engagement Process (four Roman numeral phase boxes), 6 Engagement
Model and Structure (table plus routing paragraph), 7 Deliverables and Reporting
Cadence, 8 Roles and Responsibilities, 9 Confidentiality (survives two years),
10 Term and Termination (Term, Termination for Convenience, Termination for
Cause, Tail Period of twelve months, Effect of Termination), 11 Fees and Billing
(Retainer Fee, Success Fee, Statutory Costs and Expenses), 12 Governing Law and
Dispute Resolution (Mumbai arbitration), 13 Acceptance (bordered signature table,
Company on the left, Advisor on the right).

All of this is generated by the script; the full wording is in
`references/fixed_clauses.md`.

## Workflow

### 1. Gather the inputs

If a client document (pitch deck, website, financials, email thread, earlier
draft) is available, pull as much as possible from it first and ask only for
what is missing. Use `ask_user_input_v0` for choice style questions where it
helps, otherwise ask directly. Fields:

- **Client legal name** (e.g. "Example Industries Private Limited")
- **Brand / trade name**, if any (e.g. "Example Co"). Optional. When given, the
  letter says "operating under the brand <brand>" and the cover reads
  "Prepared for <legal name> (<brand>)".
- **Short name**, the defined term used throughout (e.g. "Example Co"). Default to
  the brand name, else a sensible short form of the legal name.
- **Client registered office address**, for the Preamble. Mandatory; the
  approved format names both parties' registered offices. Sample Advisory's address
  is fixed in the script.
- **What the client's business does**, one to two sentences, for Section 2.
- **Monthly retainer fee**, MANDATORY, always ask. Written as
  `Rs. 1,00,000/- (One Lakh)`; the script adds "plus applicable taxes".
- **Success fee**, MANDATORY QUESTION, always ask, never skip or default
  silently. Two valid answers:
  - a fixed percentage of funds raised (e.g. "2%"), which the script writes as
    "a success fee of 2% of the total funds raised through any transaction
    sourced, facilitated and substantially assisted by Sample Advisory"; or
  - "to be decided mutually", which reproduces the Example Co wording
    (percentage decided mutually as and when applicable). Pass an empty string.
- **Term** in years (default three). Ask only if the user signals a different
  term; otherwise use three.
- **Date** of the mandate (e.g. "16th September 2026").
- **Client signatory** name with title plus designation (e.g. "Mr. A. Sample",
  "Director"). Mandatory; the approved format prints it in the signature table.
- **Sample Advisory signatory** name with title plus designation. Default is
  Mr. A. Partner, Director; confirm for each mandate since it can vary
  (B. Partner, President ECM, is the other common signatory).
- **Place** of signing (default Mumbai).

Do not ask about exclusivity, billing cycle, termination, Tail Period,
confidentiality, roles, expenses or governing law. These are fixed in the
approved template.

### 2. Draft the client specific narrative

Only one part is genuinely bespoke: the opening of Section 2, one to two
sentences describing what the client does, using only facts the user supplied
(never invent financials). Match the Example Co register, for example:

> Example Co is engaged in the manufacturing of PVC ceiling, wall and panel
> products, together with B2B trading of panels.

The script appends the fixed sentence "As the Company pursues its growth plans
and expansion strategy, <short name> wishes to bring on a dedicated Strategic
Advisor and Growth Partner..." so do not repeat that idea in the description.

The six pillar bullets in Section 3 default to the approved Example Co wording with
the short name substituted. Override one via `pillar_bullets` only when the user
asks for client specific wording under a pillar.

Show the user the business description (plus any bullet overrides) before
generating, and adjust on feedback.

### 3. Build the content JSON

Follow `assets/content.schema.json`; `references/sample_content.json` is the
filled Example Co example. Shape:

```
client:      { legal_name, brand_name, short_name, registered_office }
engagement:  { title_line1, retainer_fee, success_fee_pct, term_years_words, term_years_number, date_display }
background:  { business_description }
pillar_bullets: [ optional overrides by position, A to F ]
signature:   { client_name, client_designation, advisor_name, advisor_designation, place }
```

The script refuses to run and lists any missing mandatory field.

### 4. Generate the docx

```bash
node scripts/generate_mandate.js content.json <Short Name>_Mandate_Letter.docx
```

The script reproduces the Example Co layout: firm logo centred in the
header on every page; the official footer strip (address, phone, email,
website, CIN, QR code) plus "Page X of Y" on every page; Book Antiqua 10.5pt
throughout; navy, gold and cream palette; cream label info tables; navy pillar
bars; numbered stage boxes and Roman numeral phase boxes; ordinal superscripts
("3rd", "16th") inside the Engagement Model table and signature table; and the
bordered seven row signature table with blank signature lines.

Never insert a signature or company stamp image. The approved PDF shows
Sample Advisory's signature and stamp because it was executed after generation;
the generated letter always leaves both signature lines blank for physical
or digital execution.

### 5. Convert to PDF and verify

Run the font setup once per session first. It maps Book Antiqua to TeX Gyre
Pagella (a metric compatible Palatino clone) so the PDF matches the approved
look instead of falling back to a sans serif font. The docx still names Book
Antiqua, so Word renders the true font.

```bash
bash scripts/setup_fonts.sh
python /mnt/skills/public/docx/scripts/office/soffice.py --headless --convert-to pdf <file>.docx
pdftoppm -jpeg -r 80 <file>.pdf page
```

View every rendered page before presenting. Check: the client names and address
are correct everywhere, fee and date are right, the success fee paragraph
matches the user's answer, both signatories are correct, no pillar bar is left
alone at the bottom of a page, and the document runs to about seven pages.

### 6. Present both files

Copy the `.docx` and `.pdf` to `/mnt/user-data/outputs/` and call
`present_files` with both paths, docx first.

## House style notes specific to this document

This letter reproduces an approved legal template, so its wording is kept as
approved, including "and" (not "plus") in running text, which is how the
executed Example Co mandate reads. The template already avoids the word "or"
(for example "and any other route"); keep it that way in any bespoke text.

Two hyphens in the approved PDF were removed to honour the no hyphen rule:
"fund-raising" reads "fund raising" and "four-stage" reads "four stage". The
Indian currency notation "Rs. 1,00,000/-" is kept as is, since the trailing
"/-" is standard fee notation rather than a hyphen in prose.

Fiscal years in any bespoke text use the slash format (FY 2025/26). Never
describe Sample Advisory as an investment banker; the Section 3 disclaimer states
Sample Advisory is not a SEBI registered Merchant Banker and must stay intact.
