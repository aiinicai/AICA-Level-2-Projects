# Fair Share – Expense Sharing App

**Capstone Project | AICA Level 2 | Batch 120**  
**Submitted by:** Rohan Mittal

## Project Overview

Fair Share is an expense-sharing application designed to help friends, families, and groups manage shared expenses. It simplifies recording payments, splitting costs, and keeping track of who owes whom.

## Key Features

- Create groups for trips, household expenses, office activities, and other shared costs.
- Record expenses and identify who paid.
- Split expenses between participants.
- View balances and track amounts owed between users.
- Manage expenses shared directly with friends.
- Record settlements to keep balances updated.

## Practical Use Cases

- Sharing travel expenses with friends or family.
- Managing shared household bills.
- Tracking office lunches and group activities.
- Maintaining clear records of payments and settlements.

## Use of AI

This project explores how AI-assisted development tools can help turn a practical idea into a working application. Google AI Studio was used to support application development, refine the user interface, and troubleshoot issues.

## Project Objective

To create a simple and user-friendly tool that improves transparency in shared finances, reduces manual calculations, and makes settling expenses easier.
