# App source (core)

These are the files that hold all of the app's logic. They can be read and audited on their own.

| File | Purpose |
|---|---|
| `src/lib/parse.ts` | Reads and validates the uploaded Excel workbook (four sheets) |
| `src/lib/rules.ts` | Limits and settings, with their legal sources |
| `src/lib/rpt.ts` | The checks (C1 to C7, L1, L2), the market price test, the Ind AS 24 summary and Form AOC-2 |
| `src/lib/acceptance.ts` | Acceptance test against the independent answer key (24 tests) |
| `src/lib/summary.functions.ts` | Server function that sends computed results only to Lovable AI for the audit committee summary |
| `src/lib/format.ts` | Indian number and date formatting |
| `src/data/sampleData.ts` | Sample data for the fictitious company, generated by `scripts/gen_rpt.py` |

The user interface (React, TanStack Router, Tailwind and shadcn/ui) was generated by Lovable from the specification in `prompts/lovable_build_prompt.md` and is not reproduced here. The app runs entirely in the browser; the only server code is the AI drafting function.
