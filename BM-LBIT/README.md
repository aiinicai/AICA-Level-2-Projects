*/ “BM-LBIT” – A tool for Automatic Listing of the Books based on Racks Photo  - by Bhadresh Mehta, student of AI level 2 batch number 88, completed on 11th September 2026 at Ahmedabad.
*/ The Problem statement, In libraries, there are thousands of books, and the books are arranged vertically in a variety of shelves or Racks. Now, if you want to prepare a fresh list of all the books manually by writing the name of the book and all other details, it will take...hours and hours.
*/ This software, Library Book Image Tool, LBIT, automatically prepares a fresh list of all the books based on the photos, captured on mobile and stored in a folder.
*/ It gives list in an Excel file along with image of the book.
