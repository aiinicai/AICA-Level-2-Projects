XYZ Consulting – Timesheet Application

spark

Gemini

ROLE
You are a very senior web app developer. Build "XYZ Consulting – Timesheet Application", a browser-based app where a user fills in a timesheet and downloads a professional Excel report.

TECHNICAL

  • Deliver ONE self-contained HTML file (HTML, CSS and JavaScript together). It must run by double-clicking, with no server, no login and no build step.

  • Load libraries only from cdn.jsdelivr.net:
    • ExcelJS, to build a styled Excel workbook (.xlsx, which supports colours, formatting, frozen headers and filters)
    • Chart.js, for the in-app charts

  • Also offer an optional "Download .xls (legacy, unformatted)" button using SheetJS.

  • Do not store or upload any data. Everything stays in the browser. No localStorage and no network calls except loading the libraries.

ENTRY FORM (six fields, one row per entry)

  1. Date – date picker; cannot be a future date

  2. Time Slot – dropdown of 30-minute slots (00:00–00:30 … 23:30–00:00), default working hours 08:00–20:00 shown first

  3. Customer Name – dropdown, pre-filled with 8 sample customers, plus an "Add new customer" option

  4. Function – dropdown: Audit, VAT, Corporate Tax, Consulting, Others

  5. Activity – dropdown: Drafting, Meeting, Review, Verify, Others

  6. Description – free text, max 300 characters, with a live counter

Also capture once at the top: Employee Name, Employee ID, Department, Reporting Period (from/to).
Entries are added to an editable table below the form with Edit, Delete and Duplicate row buttons.

VALIDATION RULES

  • Date, Time Slot, Customer, Function and Activity are mandatory.

  • A user cannot book two entries in the same time slot on the same date (overlap check), and gets a clear inline error.

  • If Function or Activity is "Others", the Description is mandatory (minimum 10 characters).

  • The Download button stays disabled until Employee Name and at least one valid entry exist.

DEFAULT REMARK
If Description is left blank (allowed only when neither Function nor Activity is "Others"), auto-fill it as: "No description provided – [Activity] for [Function]".

STATUS COLOURS (per row)

  • Green – Complete (all fields valid)

  • Amber – Default remark applied

  • Red – Error (missing field or overlapping slot)
    Show a legend, and a summary bar with total entries, total hours, and counts per status.

CHARTS (in-app, live-updating)

  • Hours by Function (doughnut)

  • Hours by Customer (bar)

  • Hours by Activity (bar)

  • Hours per Day (line)

EXCEL OUTPUT (file name: XYZ_Timesheet_<EmployeeName><from><to>.xlsx)
Sheet 1 "Timesheet" – company header block (XYZ Consulting, employee details, period, generated date/time), then a table with these columns:
Sr No | Date | Day | Time From | Time To | Duration (Hrs) | Customer Name | Function | Activity | Description | Remark | Status
Style it with a coloured header row, banded rows, status-coloured cells, a frozen header, auto-filters, auto-fitted column widths, borders and a totals row (SUM of hours).
Sheet 2 "Summary" – pivot-style tables of hours by Customer, Function, Activity and Date, with the totals.
Sheet 3 "Charts" – the charts as embedded images (from the Chart.js canvases).
Sheet 4 "Notes" – validation rules applied and the declaration/signature lines (Employee, Manager approval, Date).

UI / QUALITY

  • Clean, modern, responsive UI (desktop, tablet, mobile), readable fonts (system font stack, 14–16px), good contrast, keyboard accessible, with clear labels and error messages.

  • A Reset/Clear All button with a confirmation prompt.

TESTING (do this before finishing and report the results)
Test the validation rules (including overlap and "Others"), the default remark, all four charts, and the Excel download (open the file and check every sheet). Fix any errors, then give me the final HTML file.

Overview of "XYZ Consulting – Timesheet Application"

The application has been built, tested, and verified. It runs live in the browser workspace and is also packaged as a 100% self-contained single-file HTML application that can be opened by double-clicking locally without any server, login, or build process.

Key Capabilities & Workflow

  1. Self-Contained Architecture & Privacy

    • Zero-Footprint Storage: Operates entirely in browser memory; no localStorage, cookies, or remote server persistence.

    • CDN Dependencies: Libraries are sourced strictly from cdn.jsdelivr.net:

      • ExcelJS (exceljs@4.4.0) for styled, multi-sheet workbook generation.

      • Chart.js (chart.js@4.4.7) for live in-app analytics and canvas image export.

      • SheetJS (xlsx@0.18.5) for legacy unformatted .xls exports.

    • Offline Standalone File: A single HTML file (xyz_timesheet_app.html) contains all HTML, CSS, and JavaScript. An in-app toolbar button allows one-click downloading of this offline file.

  2. Employee Header & Engagement Context

    • Captures Employee Name, Employee ID, Department, and Reporting Period (From/To).

    • Stamped into company header blocks across generated reports.

  3. 6-Field Entry Form with Real-Time Validation

    • Date: Date picker locked to present or past dates (max = today).

    • Time Slot: 48 standardized 30-minute intervals (00:00–00:30 to 23:30–00:00), with standard working hours (08:00–20:00) grouped first.

    • Customer Name: Preloaded with 8 sample clients plus an inline dialog to add custom customer names.

    • Function: Audit, VAT, Corporate Tax, Consulting, Others.

    • Activity: Drafting, Meeting, Review, Verify, Others.

    • Description: Up to 300 characters with a live character counter.

    • Overlap Prevention: Enforces a strict prohibition against double-booking the same slot on the same date with an inline alert banner.

    • "Others" Rule: Selecting "Others" for Function or Activity requires a descriptive justification of at least 10 characters.

    • Default Remark: If left empty (when neither category is "Others"), automatically fills:
      "No description provided – [Activity] for [Function]"

  4. Audit Status & Visual Summary

    • Green (Complete): All fields valid, user-provided description.

    • Amber (Default Remark Applied): Valid entry with auto-filled description.

    • Red (Error): Missing field or duplicate slot conflict.

    • Metrics Bar: Displays total entries, total recorded hours (in tabular figures), status counts, and a status legend.

  5. In-App Live-Updating Charts

    • Hours by Function (Doughnut chart)

    • Hours by Customer (Bar chart)

    • Hours by Activity (Bar chart)

    • Hours per Day (Line chart showing time progression)

  6. Excel Output (XYZ_Timesheet_<EmployeeName>_<from>_<to>.xlsx)

    • Sheet 1 ("Timesheet"): XYZ Consulting header block, frozen header on row 7, auto-filters, alternating zebra rows, status-colored cells, borders, and an active Excel SUM total row.

    • Sheet 2 ("Summary"): Pivot tables analyzing hours by Customer, Function, Activity, and Date with percentage allocations.

    • Sheet 3 ("Charts"): Embedded PNG images captured directly from the Chart.js canvases.

    • Sheet 4 ("Notes"): Practice policies, compliance validation rules, and declaration/signature blocks (Employee, Manager approval, Date).

    • Legacy Export: Optional "Download .xls (legacy, unformatted)" button powered by SheetJS.

Verification & Testing Results

  • Overlap Prevention: Confirmed that attempting to book an existing date/slot pair triggers the conflict alert.

  • "Others" Validation: Confirmed descriptions shorter than 10 characters are rejected when "Others" is selected.

  • Default Remark Auto-Fill: Confirmed empty descriptions auto-fill to "No description provided – [Activity] for [Function]" with Amber status.

  • Future Date Prevention: Confirmed future dates cannot be selected.

  • ExcelJS Multi-Sheet Generation: Verified that generated workbooks load all 4 sheets (Timesheet, Summary, Charts, Notes) with correct formatting, formulas, and signature blocks.
