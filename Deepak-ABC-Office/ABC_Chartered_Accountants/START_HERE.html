ABC CHARTERED ACCOUNTANTS

Offline Team Office

Assignments, staff timesheets, office updates and professional reports.

1 Start the application

  1. Right-click the downloaded ZIP and choose Extract All. Extract the complete folder to Documents or another location where you can save files.
  2. Open the extracted ABC_Chartered_Accountants folder. Double-click ABC_Office.exe.
  3. Your normal web browser opens http://127.0.0.1:8765. This address is your own computer. Internet access is not required.
  4. A small server console starts, usually minimised. Keep it running while using the tool. Closing the browser alone does not stop the server.
  5. Use Start_Local.bat if you prefer a visible server console or need to read a startup error.

The package includes Python and report libraries. You do not need to install Python, run pip, install Microsoft Word or configure Google services. It is designed for 64-bit Windows 10 and Windows 11. Keep the app and runtime folders beside the executable.

2 Create the administrator

  1. On the first launch, enter your name, contact email, username and a password of 12 to 128 characters. Confirm the password and click Continue.
  2. The app shows an owner recovery key. Click Download recovery key and save it privately. It can reset the owner password. It is replaced each time owner recovery is used.
  3. Click I have saved the key. The dashboard opens.

There is no preset shared administrator password. The contact email is stored for reference; this offline application does not send email.

3 Set up the office registers

  1. Open Employees → Add record. Enter name, username, contact email, role, designation and a temporary password. Staff can share the office contact email, but must have individual usernames and passwords.
  2. Give each employee their temporary password privately. They must change it at first login.
  3. Open Clients and add client records.
  4. Review Nature of work and Periodicity. Standard entries are already provided.
  5. Open Assignments → New assignment. Select client, nature of work, period, financial year, employee and reviewer. Enter allocation date, target date, priority and instructions; save.

4 Staff daily routine

  1. Sign in with your own username and password. Sessions expire after one hour.
  2. Review your assigned work on the Dashboard or Assignment register.
  3. Staff may change their own open assignment status to In progress or Ready for review. Admins and Managers can allocate, review, complete and cancel work.
  4. In Timesheets, select work date and an assignment allocated to you, or select Idle time.
  5. Enter From and To as 24-hour HH:MM, for example 09:30 and 10:30. The tool calculates the duration. End time must be later on the same date.
  6. Select Billable or Non-billable and enter work details. Idle time is Non-billable.
  7. Save and confirm that the entry appears in the register. You can edit your own entries. Overlapping time ranges on the same date are rejected.

Daily expectation is nine hours, including idle time. Idle time over one hour is highlighted but may be saved. Admins/Managers may ask for an explanation; staff can respond below the daily summary. Backdated entries are allowed. Earlier duration-only records, if present in the database, retain their recorded hours.

5 Dashboard filters and office updates

The Dashboard excludes Completed and Cancelled work by default. Use the employee and status selectors to select several values. Target filters include Overdue, Due today and Due within seven days. The Assignment register includes closed work.

Admins and Managers can publish, edit and archive announcements in Office Communication and Updates. Staff view active announcements. The open announcements tab checks for updates every fifteen seconds.

6 Generate reports

  1. Admins/Managers open Reports.
  2. Select Staff or Client and an inclusive From/To date range.
  3. For Staff, select one employee and optionally one client. All-client staff reports include idle time.
  4. For Client, select one client and optionally a single assignment. Client reports exclude idle time.
  5. Click Preview report, Download Word or Download PDF.

Reports show the selected name and period, grouped dates, client, nature of work, From, To, hours worked and billing classification. Client reports also identify the staff member. Daily and period totals are included. 1:30 means one hour thirty minutes, not 1.30 decimal hours. Report generation does not need Microsoft Word or an internet connection.

7 Share across staff computers on the office LAN

  1. Choose one host computer to hold the office database. Complete first-time administrator setup on that computer in local mode.
  2. Close its running server console. Start Start_Office_Server.bat.
  3. Read an Office network address in that console, for example http://192.168.1.50:8765. Use the actual address printed on your computer.
  4. If Windows asks about network access, enable access for your trusted private office network.
  5. Staff connected to that same office network open the host address in their browsers and sign in with their individual accounts. No Python installation is needed on staff computers.
  6. Keep the host switched on and its server console running. Give the host a fixed/reserved office IP if possible so its address remains stable.

Separate copies started independently on different computers have separate databases and do not synchronise. Shared assignments, reports and real-time office updates require everyone to connect to the same running host. Keep the database on the host's local drive; share access through the application, not by opening the SQLite file over a network drive.

8 Password resets

Click Forgot password and enter your username. An Admin/Manager sees the pending request on the Dashboard, verifies the employee and issues a temporary password. The employee changes it on login. Offline mode does not send recovery emails. If the owner loses access, choose Forgot password → Owner recovery and enter the owner's username, saved recovery key and a new password; save the replacement key.

9 Data and backups

Data is saved in data/office.sqlite3 beside the executable. A dated consistent backup is made in data/backups when the server starts on a new date. Admins/Managers can also use the Backups tab to download a complete database backup. Create a backup after the first configuration and regularly during office use. Keep copies on a separate drive. The database stores password hashes, not plaintext passwords.

To move computers, stop the server, copy the complete folder including data, and start it on the new host. To update the software later, retain your data folder and replace only application/runtime files as instructed. This package starts a fresh ABC office; it does not automatically import or synchronise the earlier Google spreadsheet.

Restore a database backup

  1. Stop the server completely and ensure staff have finished using it.
  2. Make a copy of the current entire data folder before changing anything.
  3. Replace data/office.sqlite3 with the chosen backup file, renaming the backup to office.sqlite3.
  4. Remove old office.sqlite3-wal and office.sqlite3-shm files if they remain after shutdown. These files must not be mixed with a restored database.
  5. Restart the application and verify the restored records. Restore returns the entire database, including accounts and passwords, to its backup state.

10 Troubleshooting

SituationAction
Browser does not openUse Start_Local.bat and then open http://127.0.0.1:8765 manually. Keep the console open.
Cannot start or saveExtract the whole ZIP to a writable local folder. Keep runtime and app beside ABC_Office.exe. Read the console message using Start_Local.bat.
Staff cannot connectUse Start_Office_Server.bat on the host after local setup. Check the host is awake, both PCs share the office network, and its private-network firewall permits access.
Session expiredLog in again. Saved records remain in the database.
Record changedRefresh before editing. Someone else updated the same record.
Report too largeUse a shorter period. Each report is limited to 1,000 entries and 8 MB.
Other operation failedRead data/error.log. Run Run_Self_Test.bat; it uses temporary data only.

The Windows x64 executable is included with a portable runtime. Application tests and browser/report checks were performed in a Linux build environment; native Windows execution has not been verified here.
