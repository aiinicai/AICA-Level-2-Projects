ABC CHARTERED ACCOUNTANTS OFFLINE TEAM OFFICE

Application source: ../app/app.py, ../app/reports.py and ../app/index.html.
The application uses the standard Python HTTP server and SQLite.
The HTML interface was adapted from the existing Apps Script interface.
There are no external scripts, fonts, CDNs, AI services or cloud database calls.

Windows package:
- Official CPython 3.12.10 Windows x64 embedded distribution.
- Windows x64 wheels listed in requirements.txt are bundled under runtime/Lib/site-packages.
- A native Win32 GUI launcher starts the bundled Python interpreter in isolated mode.
- The launcher uses KERNEL32.dll and USER32.dll only. Source: launcher.c.
- The executable is a launcher, not a single-file archive. Keep the entire folder.

The launcher was cross-compiled with Zig 0.14.1 for x86_64-windows-gnu.
Example (Zig include path must match your installation):
zig cc -target x86_64-windows-gnu -O2 -fno-builtin -fno-stack-protector -nostdlib -isystem PATH_TO_ZIG/lib/libc/include/any-windows-any -Wl,--entry,mainCRTStartup -Wl,--subsystem,windows launcher.c -lkernel32 -luser32 -o ABC_Office.exe

Python development run (Python 3.12 plus requirements):
python app/app.py
python app/self_test.py

Data defaults to data/office.sqlite3 beside the executable.
Optional command-line flags: --lan, --port 8766, --data-dir PATH, --no-browser.
Do not serve app/index.html as a static file: the server injects its process key.

Validation:
- Python source compiled and thirteen functional and backup-handle tests passed.
- Browser workflows tested against the running Python server.
- Word and PDF output rendered and visually inspected.
- Windows PE structure and bundled dependency files checked.
- Native Windows execution could not be tested in this Linux environment.
