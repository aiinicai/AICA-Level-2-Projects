{{ firm.firm_name }} — the firm's standing answers

Answer each question once here and every engagement created afterwards starts with these answers already given, so a clean file does not have to be answered from scratch for each client and each year.

Any engagement can override any of them. Open the dropdown in that engagement's workspace, change it and save; the change applies to that report only and never comes back here.

These are the firm's answers, not one client's. They apply to every client in {{ firm.firm_name }}. A second firm in this installation keeps its own.

What saving these means.

  • An answer taken from this sheet counts as answered for readiness and for the export block. An engagement nobody has opened will read 100% ready and can be exported on the strength of these answers alone.
  • It is still recorded as coming from here rather than from a person looking at that client's file — the audit log and the change history show the difference even though readiness no longer does.
  • Editing this sheet never changes an engagement that already exists. A file in progress must not shift under you. To bring these into an existing engagement, use the button on its workspace.
