# Construction Contract POCM Analyzer

## Overview

Construction Contract POCM Analyzer is a Python-based financial management application designed to support construction contract accounting using the Percentage of Completion Method (POCM).

The application helps analyze construction projects by calculating project completion, revenue recognition, construction costs, profit, billing, collections, retention, and contract balances.

## Key Features

- Percentage of Completion Method (POCM) calculation
- Cost-to-cost percentage of completion
- Contract revenue and construction cost analysis
- Gross profit calculation
- Billing and collections tracking
- Retention calculation
- Contract asset and contract liability analysis
- Expected-loss assessment
- Project data management
- SQLite database storage
- Excel import and export
- PDF reporting
- CSV reporting
- Calculation history
- Desktop graphical user interface

## Technology

- Python
- Tkinter
- SQLite
- ReportLab
- OpenPyXL
