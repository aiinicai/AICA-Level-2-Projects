You are assisting a Chartered Accountant in building a business risk assessment tool based on financial ratio analysis for a client company.
Write a Python script that computes this from input financial data.

Company details:
- Name of Company: Trident Engineering Pvt. Ltd.
- Industry: Manufacturing
- Financial Statements Available: 3 years of summarized Balance Sheet and P&L data (FY 2023-24, FY 2024-25, FY 2025-26)

Task 1 — Data Structure:
Create a Python dictionary or list of dictionaries holding 3 years of sample financial data with these fields (use realistic manufacturing-company figures):
- Current Assets, Current Liabilities, Inventory
- Total Debt, Total Equity, EBIT, Interest Expense
- Net Profit, Revenue, Capital Employed
- Operating Cash Flow
- Average Inventory, Average Debtors, Total Assets

Task 2 — Ratio Calculation Functions:
Write separate functions to calculate, for each year:
1. Liquidity: Current Ratio, Quick Ratio
2. Solvency: Debt-Equity Ratio, Interest Coverage Ratio
3. Profitability: Net Profit Margin, ROCE, ROE
4. Efficiency: Inventory Turnover Ratio, Debtors Turnover Ratio, Asset Turnover Ratio
5. Cash Flow: Operating Cash Flow to Total Debt Ratio

Each function should take the year's data dictionary as input and return the computed ratio value (rounded to 2 decimals).

Task 3 — Risk Scoring Logic:
1. Write a function that takes a ratio name and its value, and returns a risk score (1 = High Risk, 2 = Moderate Risk, 3 = Low Risk) based on these benchmark rules (implement as if/elif conditions):
   - Current Ratio: <1.0 = 1, 1.0-1.5 = 2, >1.5 = 3
   - Quick Ratio: <0.8 = 1, 0.8-1.2 = 2, >1.2 = 3
   - Debt-Equity Ratio: >2 = 1, 1-2 = 2, <1 = 3
   - Interest Coverage Ratio: <1.5 = 1, 1.5-3 = 2, >3 = 3
   - Net Profit Margin: <5% = 1, 5-10% = 2, >10% = 3
   - ROCE: <10% = 1, 10-15% = 2, >15% = 3
   - Inventory Turnover: <4 = 1, 4-8 = 2, >8 = 3
   - Debtors Turnover: <6 = 1, 6-10 = 2, >10 = 3
   - Operating Cash Flow to Debt: <0.1 = 1, 0.1-0.2 = 2, >0.2 = 3
2. Define category weights as a dictionary: Liquidity 25%, Solvency 30%, Profitability 25%, Efficiency 20% (Cash Flow ratio can be grouped under Solvency).
3. Write a function to calculate the Composite Business Risk Score per year as a weighted average of category scores, scaled to 0-100.
4. Classify the final score into a risk band: 0-40 = High Risk, 41-70 = Moderate Risk, 71-100 = Low Risk.

Task 4 — Output:
1. Print a formatted ratio table for all 3 years (ratio name, year-wise values, trend arrow ↑/↓/→).
2. Print a risk scoring table (ratio, score per year, category, weight).
3. Print the Composite Risk Score and risk band for each of the 3 years.
4. Print a short auto-generated summary (2-3 lines) identifying whether risk is improving or deteriorating year-on-year, and which 1-2 ratios are the biggest drag on the score (based on lowest scores).
5. Use only Python standard library (no external packages) so it runs without installation. Use clear function names and comments throughout, since this will be explained in a demo video.

Note: All financial figures are illustrative/fictional, and benchmark thresholds are general in nature — to be adjusted per industry norms and professional judgment in actual use.
