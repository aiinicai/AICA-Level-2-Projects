====================================================================
  AuditLens - how to start it
====================================================================

THE EASY WAY

  1. Make sure you have EXTRACTED this folder from the ZIP.
     A .bat file will not run from inside a zip preview window.

  2. Right-click run-windows.bat, choose Properties, and if you see
     an "Unblock" tick-box at the bottom, tick it and press OK.
     Windows blocks scripts that came from the internet.

  3. Double-click run-windows.bat.


IF DOUBLE-CLICKING OPENS THE FILE IN NOTEPAD INSTEAD OF RUNNING IT

  Your .bat file association is pointing at a text editor. Do not
  fight it - use the typed commands below instead. They work no
  matter what your file associations say, and they look better on
  camera anyway.


THE TYPED WAY - WORKS ALWAYS

  1. Open this folder in File Explorer.

  2. Click once in the address bar at the top, type   cmd   and
     press Enter. A black Command Prompt window opens, already in
     this folder.

  3. Type these four lines, pressing Enter after each. The first
     three are only needed the very first time.

       py -3 -m venv .venv
       .venv\Scripts\activate
       pip install -e ".[dev]"
       python -m auditlens.launch

  4. Your browser opens by itself once the server is ready.
     Click "Use the sample client".

  Every time after that, only two lines are needed:

       .venv\Scripts\activate
       python -m auditlens.launch

  To stop it: press Ctrl+C, or close the window.


TO RUN THE TESTS (worth showing in the video)

       .venv\Scripts\activate
       python -m pytest


IF PYTHON IS NOT FOUND

  Install Python 3.10 or later from https://www.python.org/downloads/
  and TICK "Add python.exe to PATH" on the first screen of the
  installer. Then close and reopen the Command Prompt.


DOCUMENTATION

  The .md files are plain text and are meant for GitHub. PDF copies

       AuditLens.pdf           - the full README
       PROJECT_SUMMARY.pdf     - the two-page summary
       docs\recording_guide.pdf - how to record the video
       docs\statutory_basis.pdf - the authority for every routine
