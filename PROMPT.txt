You are a **senior Python software architect and desktop application developer** with expertise in Indian Income-tax/TDS/TCS compliance documents, PDF text extraction, OCR, document classification, and Windows desktop applications.

I want you to develop a **complete, production-ready Python application** called:

# TDS & TCS Certificate PDF Auto-Renamer

## 1. OBJECTIVE

Develop a Python desktop application that allows the user to select a folder containing multiple Indian **TDS and TCS certificate PDF files**.

The application must:

1. Read every PDF in the selected folder.
2. Extract text/data from each PDF.
3. Identify the type of TDS/TCS certificate.
4. Identify whether the certificate relates to the:

   * **Income-tax Act, 1961**, or
   * **Income-tax Act, 2025**
5. Extract the **Deductee/Collectee name** from the certificate.
6. Rename the PDF using the **Deductee/Collectee name**.
7. Preserve the original PDF contents without modification.
8. Process hundreds or thousands of PDFs in batch.
9. Provide a detailed processing log.
10. Handle duplicate names intelligently so that no existing file is overwritten accidentally.

The application should primarily be designed for **Indian Chartered Accountants, tax consultants, accountants, businesses and TDS/TCS compliance professionals**.

# 7. PDF PROCESSING ENGINE

Use suitable Python libraries.

Prefer:

* `PyMuPDF` / `fitz` for PDF text extraction.
* `pypdf` as an additional fallback.
* `pdfplumber` where table/position extraction is useful.
* `pytesseract` + suitable OCR engine for scanned PDFs.

Use this processing hierarchy:

```text
PDF
 ↓
Attempt native text extraction
 ↓
Is sufficient text available?
 ├── YES → Extract data
 └── NO

       ↓
     OCR
       ↓
     Extract data
```

# 11. SAFE FILE NAME CLEANING

Deductee names may contain Windows-invalid characters.

Windows-invalid characters include:

```text
\ / : * ? " < > |
```

The application must sanitize these characters.

Example:

```text
ABC / XYZ PRIVATE LIMITED
```

becomes:

```text
ABC - XYZ PRIVATE LIMITED.pdf
```

Also:

* Remove leading/trailing spaces.
* Remove trailing periods.
* Collapse repeated spaces.
* Replace line breaks with spaces.
* Remove invisible/control characters.
* Preserve meaningful punctuation.
* Preserve Unicode characters where Windows supports them.
* Limit filename length to a safe Windows-compatible length.

Do not unnecessarily remove Indian names or meaningful characters.
