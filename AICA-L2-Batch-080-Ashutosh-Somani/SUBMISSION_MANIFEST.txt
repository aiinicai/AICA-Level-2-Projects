KNOWN LIMITATIONS / ITEMS FOR MANUAL REVIEW
----------------------------------------------------------------
1. .secret is tracked in the live project's git history from its very
   first commit, contradicting the project's own "never store secrets in
   source control" rule. Not included here, but the user should consider
   rotating the key and/or scrubbing it from git history before any wider
   distribution of the live repository (separate from this submission
   folder, which does not contain it).
2. requirements.txt does not list `reportlab`, which
   tests/test_ocr_stage13.py imports directly. Tests only ran cleanly here
   after installing it manually.
3. Version number is inconsistent across the project: config.default.ini,
   launcher.py, and CHANGELOG.md all say 1.0.1, but
   START_BANK_CONVERTER.bat's console banner, docs/TECHNICAL_FACT_SHEET.md,
   and docs/SUBMISSION_CHECKLIST.md still say 1.0.0.
4. A stray .git/index.lock file exists in the live working copy and could
   not be removed from this environment (permission denied). It did not
   block any read-only inspection performed here, but the user should
   delete it manually before their next git operation if it persists.
5. Tests for this manifest were executed on Python 3.10.12 in a Linux
   verification environment (all dependencies installed cleanly, 186/186
   passed). The application's stated target is Windows 10/11 with Python
   3.12+; the user should re-run `python -m pytest` via
   START_BANK_CONVERTER.bat's own virtual environment on their Windows
   machine before final submission to confirm parity.
6. The working tree had uncommitted changes at packaging time (see
   "Working Tree Status" above) - verified as line-ending-only, no content
   impact on this submission.
7. static/vendor/pdfjs includes ~8 MB of .js.map source-map files for the
   vendored PDF.js viewer. These are not required to run or evaluate the
   application (debug aids only) and could be removed to shrink the
   package further; left in place by default pending the user's decision.
