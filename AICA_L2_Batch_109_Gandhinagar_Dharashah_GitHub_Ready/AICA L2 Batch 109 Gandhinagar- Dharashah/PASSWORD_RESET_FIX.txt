SmartHire AI password recovery fix

This build adds a Forgot password button and a Create your password form.

1. Stop the existing Vite server with Ctrl+C.
2. Replace your previous project folder with this extracted folder (or copy frontend/src/main.jsx into your existing frontend/src/main.jsx).
3. Keep your existing frontend/.env configuration.
4. In the frontend folder run: npm install  (only if needed) then npm run dev -- --port 5173 --strictPort
5. In Supabase Authentication > URL Configuration set Site URL to http://127.0.0.1:5173 and add http://127.0.0.1:5173/** to Redirect URLs.
6. On the login page click Forgot password?, enter your admin email, and click Send recovery email.
7. Open the NEWEST recovery email link while the Vite server is running. You should see Create your password. Set a NEW password, not your Gmail password.

Important: The frontend server must remain running while clicking the recovery link. Never share your password or recovery token.
