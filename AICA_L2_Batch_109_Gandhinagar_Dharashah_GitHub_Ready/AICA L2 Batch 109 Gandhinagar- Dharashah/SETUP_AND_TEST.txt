SMART HIRE AI — UPDATED CAPSTONE PROJECT

1. Back up your current working SmartHire_AI_Fullstack folder.
2. Extract this ZIP to a NEW folder, e.g. Desktop\SmartHire_AI_Updated.
3. Copy your existing backend\.env and frontend\.env into the corresponding folders in the new project. Never share these files.
4. In Supabase SQL Editor, run supabase\interview_scheduling.sql ONCE (if not already applied).
5. Open a terminal in frontend and run npm install (only on first setup).
6. Ensure Python requirements from backend\requirements.txt are installed (only on first setup).
7. Close previous backend/frontend server windows so ports 8000 and 5173 are free.
8. Double-click START_SMARTHIRE.cmd in the project root.
9. Sign in, open Candidates, change Human Review status and refresh to verify persistence.
10. Click Schedule interview beside a candidate. Set date/time/mode/interviewer and save.
11. Open Interviews, edit/reschedule, complete or cancel an interview.

NOTE: The launcher starts both servers automatically but their windows must stay open. It does not install dependencies or deploy the website.
The ZIP intentionally excludes all real .env files, API secrets, node_modules and compiled caches.
