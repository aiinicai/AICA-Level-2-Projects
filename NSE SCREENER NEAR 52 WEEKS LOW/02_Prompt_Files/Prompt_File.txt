AICA LEVEL 2 CAPSTONE – AI PROMPT FILE
PROJECT: NSE NEAR-52W-LOW STOCK SCREENER

AI TOOL USED: OpenAI ChatGPT

PURPOSE
This file records representative prompts reflecting the AI-assisted development process. They are not claimed to be verbatim historical ChatGPT messages

1. PROJECT CONCEPT
“I am a Chartered Accountant working on a finance analytics project. Help me design a Python application that screens NSE-listed equity stocks using transparent technical conditions. Structure the requirements into a clear development specification.”

2. SCREENING LOGIC
“Build six explicit pass/fail tests: price <=20% above 52-week low; price >=30% below 52-week high; 5-day return >=-2%; 20-day return >=-5%; current volume >=0.8 times previous 20-session average volume; price versus 20DMA >=-3%. Only stocks passing all six tests should move to the next stage.”

3. NSE DATA INTEGRATION
“Implement robust NSE data retrieval using NSE CM-UDiFF equity bhavcopy data and the NSE 52 Week High Low Report. Handle non-trading dates, source-column changes and data failures.”

4. HISTORICAL CALCULATIONS
“Create the historical-data workflow for 5-day return, 20-day return, 5DMA, 20DMA, 20DMA slope and previous 20-session average volume, with appropriate missing-data handling.”

5. SECONDARY CLASSIFICATION
“After the six-test screen, classify only 6/6 candidates as Stabilising, Watch / Mixed Signals or Falling Knife Risk using transparent deterministic rules.”

6. DESKTOP APPLICATION
“Create a professional Tkinter interface with a DD-MM-YYYY date field, Run Screener button, six-rule display and run log, while keeping the interface responsive during processing.”

7. EXCEL REPORT
“Generate a professional Excel report with Dashboard, 6_6_Candidates and Data_Audit sheets, showing dates, companies analysed, 6/6 count, screening funnel and trend classification.”

8. ROBUSTNESS / DEBUGGING
“Review the application for non-trading dates, unavailable NSE reports, changed columns, missing values, insufficient history, network failures and Excel errors. Add clear handling without changing the intended methodology.”

9. DOCUMENTATION
“Prepare professional AICA capstone documentation covering problem, objectives, methodology, data sources, workflow, technology, outputs, validation, limitations, responsible AI and run instructions.”

10. AI DISCLOSURE
“Prepare an AI-use disclosure stating that ChatGPT assisted with ideation, prompt engineering, code generation/refinement, debugging and documentation, while making clear that the final executable uses deterministic financial rules and does not itself call generative AI or a machine-learning prediction model.”
