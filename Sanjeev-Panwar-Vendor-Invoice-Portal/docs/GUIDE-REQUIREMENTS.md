# Requirements confirmed from the uploaded guide

Source: Github Repository Upload Guide.pdf, six pages, reviewed 9 November 2026. This is a guide-based interpretation, not verification of current ICAI policy or live repository state.

| Requirement/instruction | Guide location |
|---|---|
| Target: https://github.com/aiinicai/AICA-Level-2-Projects | p. 1 |
| Fork, add folder, commit, open PR; repository owner reviews/merges | pp. 1, 4-6 |
| One clearly named project folder, such as YourName-ProjectTitle | p. 6 |
| README.md describing the project | p. 6 |
| No embedded .git folder | pp. 5-6 |
| No files above 100 MB | p. 6 |
| Title and description clearly identify participant and project | pp. 4, 6 |
| Website upload under 100 files per upload, or batches; Git recommended for full folders | pp. 1, 3, 5 |

The guide does not require a video, slide deck, live public deployment, particular license, prescribed AI feature, particular dependency file, deadline, certificate details or a fixed naming convention beyond a clear folder name. Do not infer eligibility or assessment criteria from this upload guide.

README, folder structure and fork/PR submission are guide requirements. The security workflow, sample environment, architecture notes, demo plan, pinned dependencies, presentation and video script are preparation recommendations. A demo video is optional under this guide.

The guide describes main-to-main PRs and classic PAT authentication. Verify the actual default branch and available sign-in flow when submitting. Prefer interactive browser sign-in; if a token is necessary, use the minimum access needed, keep it private and never put it in a command URL or project file. No live web verification was used.
