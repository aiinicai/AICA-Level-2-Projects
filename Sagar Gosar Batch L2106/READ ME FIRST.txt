AGREEMENT COMPARE  -  portable edition
======================================

START:   Double-click  "Start Agreement Compare.bat"
         (Extract the whole zip first - right-click > Extract All. Do not run from inside the zip.)

Nothing to install: Python, the screen library (Qt) and the OCR engine (Tesseract) are inside this folder.
Windows 10 / 11, 64-bit.  No internet connection is used; documents never leave the computer.

If Windows SmartScreen warns about the .bat file: "More info" > "Run anyway" (the file is plain text - you can open it in Notepad).
If it does not open:  double-click "Troubleshoot (shows messages).bat" and send me the screen.

Screens
  Setup         choose the Word draft and the executed scan, options, Compare
  Summary       totals by severity and category, observations, documents compared
  Analysis      table of differences + OLD clause + NEW clause + the scan page with the difference outlined (all together)
  Side-by-side  every clause, old | new, red = deleted, green = added; "Changed clauses only" filter; next / previous change
  Redline       one continuous document, red strike = deleted, green underline = added
  Align & edit  fix paragraph pairing, OCR text and page rotation manually, then re-compare
  Reports       Word and PDF reports: summary first, register, comparison with scan extracts

What is new in this version
  Seal-aware text recovery   text under / after round seals and stamps (black, grey, blue, violet, red) is re-read with several image
                             treatments (OpenCV) and merged back; pages with seals are listed on the Summary tab.
  Accept change              on the Analysis tab tick the differences you find proper (Space) - or use "Accept" menu for all shown.
  Save updated Word file     Reports tab: the draft conformed to the executed copy for accepted changes - as Word tracked changes
                             or clean. OCR variances are never applied. Check low-OCR-confidence items on the scan first.
  Key figures reconciliation every amount, percentage, date and period of the draft against the executed copy (Summary tab, PDF, Word).
  Filters                    by severity, type of difference, page, search text, OCR variances, hide accepted.
  Scan reading quality       OCR confidence per page of the executed copy.

Keys:  F11 full screen | F3 / Shift+F3 next / previous difference | Space tick reviewed | Ctrl+1..7 tabs | Ctrl+Enter compare
