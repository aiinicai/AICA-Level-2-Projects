OCR QUICK TEST (FICTIONAL DOCUMENT)
===================================
1. Install all Python dependencies using: pip install -r app/requirements.txt
2. Install Tesseract OCR separately and confirm `tesseract --version` works.
3. Run the app from the app folder: streamlit run surl_checker_app.py
4. Upload sample_invoices/Fictional_Invoice_OCR_Demo_Scanned.pdf in the “Other invoice / supporting documents” uploader.
5. Expand the extraction preview. Expected suggestions include vendor Northstar Office Supplies, invoice NS-251188, invoice date 10-Dec-2025 and amount 12500.00.
6. Compare each extracted field with the original PDF. Correct the editable OCR candidate table, then tick the option to include those reviewed candidates in the unprocessed-invoice screening population only after checking the source. If any field remains uncertain, do not include it yet.

This is a controlled OCR demonstration only. It does not establish that OCR will correctly parse all vendor formats or all scanned documents.
