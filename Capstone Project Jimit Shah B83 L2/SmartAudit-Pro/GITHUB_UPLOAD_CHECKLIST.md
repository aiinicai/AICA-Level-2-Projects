# GitHub Upload Checklist

1. Create a new public or private GitHub repository named `SmartAudit-Pro`.
2. Upload the complete contents of this folder, preserving the folder structure.
3. Confirm that `README.md` displays correctly on the repository home page.
4. Confirm that `sample_data/SmartAudit_Demo_Population.xlsx` can be downloaded.
5. Add 3-4 application screenshots to the `screenshots` folder.
6. Test the installation commands shown in README.md.
7. Copy the final GitHub repository URL into the ICAI Google Form.
8. Record the demonstration using `documentation/Video_Narration_Script.md`.
9. Upload the video to YouTube as Unlisted or Google Drive with anyone-with-link access.
10. Test both links in an incognito/private browser before submission.
