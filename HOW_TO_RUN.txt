EQUITY PORTFOLIO REPORT - SV ARKA ADVISORS (version 4.2)
=====================================================

WHAT IS NEW
-----------
The program now opens as an app in your web browser. Everything is entered
on screen: entity name, valuation date, API key, the holding statement and
the report options. Nothing has to be typed in config.ini any more.
The app runs only on your computer; the browser is just its window.

ONE-TIME SETUP (about 15 minutes)
---------------------------------
1. Install Python from https://www.python.org/downloads/
   IMPORTANT: on the first screen tick "Add python.exe to PATH", then
   click "Install Now".
2. Unzip PortfolioAnalyzer.zip (replace any older version), e.g. into
   Documents\PortfolioAnalyzer.
3. Get an API key from ONE of these (add some credit and set a limit):
     Claude (Anthropic)  https://console.anthropic.com   key starts with sk-ant-
     OpenAI (ChatGPT)    https://platform.openai.com      key starts with sk-
     Google Gemini       https://aistudio.google.com      key starts with AIza

USING THE APP
-------------
1. Double-click RUN_WINDOWS.bat.
   - The first time, it installs the required packages (a few minutes).
   - A black window opens and the app opens in your browser.
     Keep the black window open while you work.
2. Step 1 - Report details:
   Name of the entity, valuation date, AI provider, API key and model.
   - Paste the key: the provider is picked automatically from the key and
     the models available to that key are listed. A wrong key, or a key
     for a different provider, is reported straight away.
   - Tick "Remember the key on this computer" to avoid typing it again
     (one key per provider is remembered).
   "Report options": web research / Screener on or off, searches per stock,
   the benchmark, and "Detailed analysis only for holdings with invested
   value of at least __%" (default 1%). Holdings below that are still in
   the totals, charts, pie charts and holdings table, but get no separate
   page, Screener data or web research (saves time and API cost).
   Set it to 0 to analyse every holding in detail.
3. Step 2 - Holding statement: click the box and choose the file, or drop
   it on the box. Accepted:
     Excel (.xlsx / .xls), CSV, PDF (broker statement, CDSL / NSDL CAS),
     Word (.docx), web-page tables saved as .xls / .html, and photos or
     scans (.png / .jpg).
   - If the file is password protected (PDF, Excel or Word), type the
     password in "File password" (CAS statements: usually your PAN in
     capitals). If you forget, the app asks for it.
   - If the holdings cannot be found automatically (scans, unusual
     layouts), the statement is read with AI using your API key.
     You can also press "Read with AI instead" at any time.
   - Old Word .doc files: open in Word and Save As .docx or PDF first.
4. Step 3 - Check the holdings: the table shows exactly what was read.
   Click any cell to correct it, press x to remove a row (e.g. mutual
   funds or bonds in a CAS), or "Add a row". The total cost updates.
5. Step 4 - "Save the report in": type a folder or press "Choose folder"
   (Desktop, Documents, Downloads and drives are listed; you can create a
   new folder there). Then press Generate report. Progress and a running
   log are shown. When it finishes: Open report, View in browser, Download
   Excel or Open folder. The files are named
     <Entity> - Equity Portfolio as on <date>.pdf   (+ Excel copy)
6. "Check connections" (top right) tests Yahoo prices, NSE / BSE lists,
   Screener.in and your AI key + web search. Use it first time,
   or whenever something does not work, and send me a screenshot.
7. "Close app" (top right) stops the program.

IF SOMETHING GOES WRONG
-----------------------
"Python is not installed"  -> repeat setup step 1, tick "Add python.exe to PATH".
The browser did not open   -> open the address shown in the black window
                              (http://127.0.0.1:8765/) in Chrome or Edge.
"Key was not accepted"     -> check the key and that the AI provider matches it.
Anything else              -> send the log shown under step 4, or the file
                              output\run_log.txt.

NOTES
-----
- The API key is stored only if you tick "Remember", in the file
  user_settings.json in this folder (plain text). Do not share the folder
  with that file inside it.
- Research is saved in the "cache" folder and reused for the same stock and
  valuation date, so running again costs nothing extra.
- Text mode (no browser) is still available:
     python portfolio_analyzer.py --cli <file>

MAC: install Python from python.org and double-click RUN_MAC.command
(first time: right-click > Open).
