2. WINDOWS 11 SMART APP CONTROL / SMARTSCREEN NOTIFICATION:
--------------------------------------------------------------------------------
Because this application is a custom standalone executable built for an academic/ICAI 
capstone project (without a multi-hundred dollar commercial code-signing certificate), 
Windows 11 "Smart App Control" or "SmartScreen" may flag it when copied via USB pen drive.

TO RUN INSTANTLY:
Option A (Standard - 5 seconds):
  1. Right-click "FinstockEventScope.exe" -> Select "Properties".
  2. At the bottom of the "General" tab, check the box: [x] "Unblock".
  3. Click "Apply", then "OK", and double-click the application to run.

Option B (PowerShell):
  1. Shift + Right-click inside the extracted folder -> "Open PowerShell window here".
  2. Type: Unblock-File .\FinstockEventScope.exe
  3. Press Enter and launch the application.

Option C (If Smart App Control is in strict enforcement):
  1. Open Windows Security -> App & browser control -> Smart App Control settings.
  2. Temporarily switch to "Evaluation" or "Off".
