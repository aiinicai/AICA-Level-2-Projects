IncentiveIQ V6.6 — Windows OCR setup
1. If Tesseract is already installed, START.bat should detect it automatically.
2. Otherwise install Tesseract from https://github.com/UB-Mannheim/tesseract/wiki (Windows installer). Keep English selected; optionally select Gujarati, Hindi and Marathi language data.
3. Restart PowerShell and START.bat. If not detected, set TESSERACT_CMD to the full executable path in PowerShell before launching, e.g. $env:TESSERACT_CMD = 'C:\Program Files\Tesseract-OCR\tesseract.exe'
4. Select Gujarat, enable automatic OCR, choose installed languages (English for English documents), and fetch or upload the PDF. Default OCR cap is 30 pages; increase if necessary. Total PDF page cap 250, file cap 20 MB. OCR can take several minutes. No cloud OCR or new Ollama model required.
5. Check original PDF for every OCR-derived number. OCR does not guarantee accurate tables or rates. Partial coverage is flagged. Existing V6.5 cache is not automatically migrated.
