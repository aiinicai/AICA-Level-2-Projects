ACCOUNTING ASSISTANT - HOW TO START
===================================

EVERY DAY (normal use)
----------------------
Double-click "Accounting Assistant" on the Desktop.
or
Double-click "Start Accounting Assistant.bat" in this folder.

That's it. You do NOT need to run the other commands every day.


FIRST TIME (or after unzipping a new version)
---------------------------------------------
Double-click "Setup or update.bat" in this folder.
It installs the official Python if needed, the libraries, checks the setup and creates the Desktop icon.
The first start of the app opens the setup wizard (Tally connection, companies, invoice folder, bank).

UPDATING LATER
--------------
Download the new acct_assistant_vX.zip into your Downloads folder, then double-click
"Update from Downloads.bat" here. It unzips over this folder and runs the setup again.
Your data and settings (in %APPDATA%\AccountingAssistant) are not touched.


START MANUALLY (if the icon ever stops working)
-----------------------------------------------
Open Command Prompt in this folder and type:

    python -m app.main


NOTES
-----
- Always type "python -m pip", never "pip". Smart App Control blocks pip.exe.
- If Windows shows a "blocked" message after unzipping: right-click the zip > Properties > tick "Unblock" > OK, then unzip again.
- TallyPrime must be open with port 9000 enabled:
  F1 Help > Settings > Connectivity > Client/Server configuration > Server/Both, port 9000.
