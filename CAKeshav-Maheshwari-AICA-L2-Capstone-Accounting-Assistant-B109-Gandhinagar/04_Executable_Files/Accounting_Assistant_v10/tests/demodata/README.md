# Test fixtures (fictional)

All data here is invented for testing. `aarohan_*` come from the demo company Aarohan Infotech Private Limited (the same books as the demo data pack); `forex_vouchers.xml` and `journal_numbers.csv` are small hand-made Tally replies for cases the demo books don't have (USD export invoice, Latin-1 narration, numbering series). They replace recordings of real client data, which are not part of this submission.
