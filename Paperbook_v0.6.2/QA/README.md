# v0.6.2 QA harness

Run from the folder containing the application:

```text
node QA/run_v062_qa.js SME_GSTAT_AppealKit_v0.6.2
```

The gate covers all earlier safety contracts plus first-page sizing, optional
Prepared by, safe subject justification, long-token wrapping, DD-MMM-YYYY
printing, drag ordering, mixed annexure numbering and multi-digit references.

Automated checks do not replace the PDF tests in `QA_PLAN_v062.md` or final
review in Adobe Acrobat Reader.
