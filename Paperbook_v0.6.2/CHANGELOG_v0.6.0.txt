SME GSTAT AppealKit - Professional v0.6.0
===========================================

1. COMPACT PROFESSIONAL INTERFACE
- Reduced unused header, banner, workflow and panel space.
- Private/offline explanation is now a one-line expandable message.
- Mobile workflow steps scroll horizontally.
- Improved keyboard focus, disabled states and small-screen usability.

2. INTELLIGENT PAGE EDITOR
- Select a range such as 1-5, 8, 12-15 or use all, odd and even.
- Select pages using thumbnails.
- Bulk rotate, include/exclude, move one place, or move to start/end.
- Undo, reset and original-byte preservation remain available.

3. EXACT PREVIEW NAVIGATION
- Optional annexure jump list selects the correct volume and physical page.
- Preview still uses the exact PDF bytes intended for the final ZIP.
- Any later change marks the preview out of date.

4. OPTIONAL DRAFT MODE
- Adds a translucent DRAFT - FOR REVIEW mark to every generated page.
- Does not lock, encrypt or restrict the PDF.
- Final filing mode remains the default.

5. PORTAL-SIZE GUIDANCE
- Measures actual bytes of each generated PDF.
- Warns if a volume is above the editable MB guide.
- Default guide follows the current GSTAT Help Centre advice of 20 MB.
- Warning is advisory; page count remains the automatic volume-splitting rule.
- Final ZIP includes an Excel-ready Portal Upload Map with file, pages, MB and hash.

6. OFFICIAL-SOURCE REVIEW
- Checked the current GSTAT portal, Help Centre FAQ and Appeal Filing User Manual.
- Kept filing checks optional and non-blocking.
- Preserved exact preview, document sequence, bookmarks, indexing and signed-original warnings.

NO FINALISATION LOCK WAS ADDED.
No broad new workflow tab, online upload or destructive PDF editing was added.
