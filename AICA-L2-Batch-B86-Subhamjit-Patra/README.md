# Pocket CFO 💼

Pocket CFO is an AI-powered personal finance companion that helps users understand, track, and improve their financial health.

The app brings together income, expenses, investments, assets, liabilities, insurance, and financial goals in one place, providing a complete view of an individual's financial position.

## Key Features

* Track net worth, assets, and liabilities
* Monitor income, expenses, and cash flow
* Set and track financial goals
* Calculate financial health score
* AI-powered Personal CFO assistant
* Retirement and wealth planning tools
* Insurance coverage analysis
* Financial decision support (Buy vs Rent, Loan Analysis, etc.)
* Monthly financial reports and insights

## Technology Stack

* Flutter
* Firebase
* Google Gemini AI
* Material Design 3

## Objective

Pocket CFO aims to simplify personal finance management and help users make informed financial decisions through data-driven insights and AI-powered recommendations.

## Disclaimer

Pocket CFO provides educational and informational insights only and should not be considered financial, investment, tax, or legal advice.
