AUDITEYE - QUICK START

OPTION 1 - EASY WINDOWS METHOD

FIRST TIME ONLY:
1. Make sure Python is installed.
2. Double-click INSTALL_REQUIREMENTS.bat
3. Wait for installation to finish.

EVERY TIME AFTER THAT:
1. Double-click START_AUDITEYE.bat
2. AuditEye will start in your web browser.

OPTION 2 - COMMAND PROMPT

Install:
python -m pip install -r requirements.txt

Run:
python -m streamlit run AuditEye_No_License.py

IMPORTANT:
AuditEye is a Streamlit web application. The .py file itself is not intended to open
by double-clicking like a normal Windows .exe program.
