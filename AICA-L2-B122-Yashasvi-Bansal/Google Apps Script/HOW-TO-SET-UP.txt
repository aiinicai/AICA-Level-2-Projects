3CD Helper – Google Drive script (Google Apps Script)

What it does: a client's data sent through a 3CD Helper client link is saved in the firm's own Google Drive
(folder "3CD Helper – Client data / <client> / AY <year>"), and the app can then list and bring in that file.
Access: only the "drive.file" scope – the script can see only the files and folders it creates itself.

In the app the firm does not edit this file by hand: Settings -> Google Drive for client data -> "copy this script"
gives the same code with the firm's own values filled in (YOUR_SUPABASE_URL, YOUR_SUPABASE_PUBLISHABLE_KEY, YOUR_FIRM_READ_KEY).

Set-up (once):
1. script.google.com -> New project -> paste Code.gs.
2. Project Settings -> tick "Show appsscript.json manifest file in editor" -> replace appsscript.json with the one here.
3. (New Google accounts) Services -> + -> Drive API -> Add (switches the Drive API on; access stays drive.file).
4. Choose "setup" -> Run -> allow access.
5. Deploy -> New deployment -> Web app -> Execute as: Me -> Who has access: Anyone -> Deploy.
6. Paste the Web app URL in 3CD Helper -> Settings -> Google Drive for client data -> Save.
