CA Statutory Compliance Risk Analyzer

Purpose
-------
This desktop application demonstrates how Python can be used to assist
Chartered Accountants and compliance teams in identifying statutory
compliance matters requiring priority attention.

Technology
----------
Python 3
Tkinter
Python Standard Library only

Features
--------
1. Enter compliance type
2. Enter particulars
3. Enter due date
4. Select current status
5. Select risk level
6. Enter responsible person
7. Enter remarks
8. Calculate days remaining or overdue
9. Assign priority classification
10. Display recommended action
11. Clear/reset the form

Priority Logic
--------------
Overdue + High Risk = CRITICAL
High Risk = HIGH PRIORITY
Medium Risk = MEDIUM PRIORITY
Low Risk = NORMAL MONITORING
Completed = COMPLETED / NO IMMEDIATE ACTION

How to Run
----------
1. Ensure Python 3 is installed.
2. Open the folder 06_Risk_Analyzer.
3. Double-click risk_analyzer.py if Python file association is enabled.

OR

Open Command Prompt in this folder and run:

python risk_analyzer.py

No external Python libraries are required.
