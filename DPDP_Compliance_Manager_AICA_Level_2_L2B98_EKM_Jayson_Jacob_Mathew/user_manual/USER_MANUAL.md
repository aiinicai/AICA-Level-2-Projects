# User manual (draft)

1. Sign in with the email and password set from your invitation. There is no public sign-up.
2. After sign-in you open your institution's workspace. A "Demo workspace" label marks synthetic sample data.
3. Build the personal-data inventory (departments, systems, vendors, processing activities).
4. Review applicability questions, then assess controls item by item. "Not assessed" stays separate and is never counted as implemented.
5. Upload evidence (private storage). A different person must verify it.
6. Submit an assessment for review. The preparer cannot approve it; the reviewer decides and the decision is recorded.
7. Track corrective actions; closing needs verified evidence.
8. Export reports. Each export is logged.

Limits: the app records an assessment; it does not certify compliance or give legal advice. Approval is an application record, not a legally recognised electronic signature.
