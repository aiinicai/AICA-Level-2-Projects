# Submission explanation and demo

## Project title
ITR Filing Preparation Assistant with Optimal Regime Selector

## Problem and outcome
A taxpayer's apparent deduction total does not by itself identify the better regime. Different standard deductions, HRA, age bands, rebate thresholds and marginal relief can change the result. Preparation also needs evidence reconciliation and a legally valid regime election. This application turns entered, reviewed facts into a reproducible comparison and an auditable decision paper.

## Professional judgment demonstrated
Explain the scope before demonstrating the UI. A competent adviser recognises where a comparison is valid, distinguishes a numerical preference from a filing election, reconciles evidence, and identifies unsupported claims. The app's explicit blockers and pending checks make those judgments visible. The complexity is in defensible calculations and review controls rather than the number of screens.

## AI contribution
The deterministic engine calculates taxes. Optional generative AI receives a previewed anonymous computation and drafts a client explanation plus unresolved-check checklist. Its text remains unapproved. AI is not used to invent statutory rules or select unverifiable deductions. Without a paid API, Copy prompt permits a manual demonstration using an approved AI tool; disclose that workflow in the presentation. Do not claim live API validation unless you actually perform it.

## Five-minute demo

1. Introduce supported AY, scope and evidence requirements.
2. Load example 01: new-regime rebate results in zero tax.
3. Load example 02: documented HRA/deductions make old numerically cheaper by Rs 92,300.
4. Load example 03: show Rs 51,500 marginal relief and Rs 10,400 new tax.
5. Show example 05 blocking a capital-gains case.
6. Return to example 02; show scenarios and explain that extra investment is not the same as tax saved, and no backdating is permitted.
7. Preview an AI explanation prompt; demonstrate a reviewed draft if available.
8. Enter a reviewer, chosen regime and reasons; export the Excel working paper and inspect inputs, slabs and pending checks.
