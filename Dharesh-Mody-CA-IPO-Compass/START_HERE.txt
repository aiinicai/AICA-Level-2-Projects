CA IPO COMPASS - LOCAL DASHBOARD

1. Close the previous IPO Compass application.
2. Extract ALL files from this ZIP into a new folder.
3. Open the ca_ipo_compass folder.
4. Double-click START_IPO_COMPASS.cmd.
5. Keep its command window open while you use the dashboard in your browser.

Your existing Python installation is sufficient. No pip commands are needed.
Your saved records are reused from your Windows user profile.

The browser address starts with 127.0.0.1. This is your own computer;
there is no domain, online hosting account or sign-in.

The launcher opens Microsoft Edge or Google Chrome directly. Source links
opened from the dashboard stay in that modern browser.

Refresh & analyse all retrieves the issue list and researches every open
and upcoming IPO. The first run can take several minutes while it reads
company prospectuses. See Data & sources for progress and any failures.

If the browser does not open, copy the address printed in the command
window into Chrome or Edge. Do not open index.html directly.

If startup fails, run CHECK_SETUP.cmd and share IPO_Compass_Diagnostics.txt.
Full source details, calculations and limitations are in README.md.

ABOUT THE "SMARTSCREEN" WARNING
Windows flags every file extracted from a downloaded ZIP as "from the
internet", and SmartScreen asks "Run?" for a flagged .cmd file. That question
appears BEFORE the launcher starts, so no program can skip it for a fresh
download. Two ways to never see it:

1. Before extracting a new ZIP: right-click the ZIP > Properties > tick
   "Unblock" (bottom of the General tab) > OK, then Extract All. Nothing
   inside is flagged, so nothing asks.
2. Or click Run once. The launcher then clears the flag from this folder and
   checks that it worked; SmartScreen will not ask again for THIS folder.

If a new version asks again, it is because the new ZIP is a new download.
To avoid that when updating: keep using your already-unblocked folder, and
copy the new ZIP's app folder and .py files over it (Python files never show
this warning). Do not run the .cmd from the new extraction.

If SmartScreen says it "can't be reached", your PC cannot contact Microsoft's
check service (offline, firewall or proxy). Run is still safe for files you
trust; the steps above are what stop the question from being asked.
