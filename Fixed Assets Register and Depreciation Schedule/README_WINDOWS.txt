================================================================================
FIXED ASSET REGISTER & DEPRECIATION CALCULATOR (WINDOWS PACKAGE)
Companies Act, 2013 (Schedule II) & Income Tax Act, 1961 (Section 32)
================================================================================

INCLUDED FILES IN THIS DOWNLOADABLE PACKAGE:
1. Launch_Fixed_Asset_Register.bat
   - Double-click this file on any Windows PC to launch the application.
   - Pre-loaded with 10 realistic sample assets across all Schedule II and
     Income Tax Act blocks (FY 2022-23 through FY 2026-27).

2. fixed_asset_register.py
   - Pure Python Standard Library desktop application (uses tkinter, json,
     csv, datetime, math, os). Requires zero external pip libraries.
   - Auto-loads "fixed_assets_register.json" containing 10 sample assets.

3. fixed_assets_register.json & Sample_Fixed_Assets_Data.csv
   - Pre-populated sample database and Excel-compatible CSV file containing
     10 sample fixed assets (Factory Building, Office Building, CNC Machine,
     Laser Cutting Line, Rack Servers, Workstations, HVAC System, SUV,
     Laptop Fleet, and ERP Software License).

4. Build_Standalone_Windows_EXE.bat
   - Double-click this script on a Windows PC with Python to compile
     "fixed_asset_register.py" into a single standalone Windows executable
     ("Fixed_Asset_Register.exe") using PyInstaller.

5. Fixed_Asset_Register_Standalone.html
   - Self-contained interactive Fixed Asset Register modal app that runs in
     Microsoft Edge, Google Chrome, or Firefox on any Windows PC without
     requiring Python installation.
