CA DocuFlow AI — How to Run
============================

This folder contains the full, runnable source code of the application
(see source_code/ in this offline copy; on GitHub the same source code is
simply the repository root, so it isn't duplicated there). A standalone
.exe was also built and verified during development (using PyInstaller),
but with all GUI/PDF/AI libraries bundled it is well over 200 MB, which
exceeds the size limits of most ZIP-upload forms. It is therefore
distributed via a GitHub Release instead of being embedded here — see the
link in the Project Summary Document (Section 1 and Section 15).

There are two separately runnable parts:

1) The desktop application (the main deliverable)
---------------------------------------------------
To run it directly from source (Windows 10/11, Python 3.12+):

    cd source_code
    python -m venv .venv
    .venv\Scripts\activate
    pip install -r requirements.txt
    python app.py

To build your own standalone .exe:

    pip install pyinstaller
    pyinstaller pdf_office_utility.spec

Output: source_code\dist\CADocuFlowAI\CADocuFlowAI.exe

Two optional dependencies are external programs, not Python packages, and
must be installed separately if you want to use those specific features
(everything else works without them):
  - Tesseract OCR (for the OCR / Scan tab): https://github.com/UB-Mannheim/tesseract/wiki
  - LibreOffice (Word-to-PDF fallback if Microsoft Word isn't installed):
    https://www.libreoffice.org/

2) The optional "Team Deployment" web/API platform (webapi/)
---------------------------------------------------------------
A separate multi-user maker-checker web service, NOT bundled into the
desktop .exe. From the same source_code folder (same virtual environment):

    set DOCUFLOW_ADMIN_PASSWORD=choose-a-strong-password
    uvicorn webapi.app:app --reload

Then open http://127.0.0.1:8000/ in a browser.

Full setup, architecture, feature list, and troubleshooting details are in
source_code\README.md, and a plain-language usage guide is in
source_code\USER_MANUAL.md.
