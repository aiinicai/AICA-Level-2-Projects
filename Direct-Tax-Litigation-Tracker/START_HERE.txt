DIRECT TAX LITIGATION TRACKER
=============================

QUICK START FOR EVALUATORS

1. REQUIREMENT
   Install Node.js 18+.
   npm is included with Node.js.

2. OPEN THIS FOLDER
   Open Command Prompt / PowerShell in the folder that contains:
      package.json
      README.md
      server
      src

3. INSTALL DEPENDENCIES
   npm install

4. START THE APPLICATION
   npm run dev

5. OPEN THE BROWSER
   Use the Vite URL displayed in the terminal.
   Usually:
      http://localhost:5173/

6. DEMO LOGIN
   User ID : admin
   Password: Admin@123

7. IMPORTANT
   Keep the terminal window open while the application is running.

   http://localhost:5173/ is a LOCAL address.
   It will not work on another computer unless that computer
   is running its own local application or the application is deployed online.

8. GITHUB
   Repository:
   https://github.com/jyotikauricai-blip/AICA-Level-2-Projects

   Project folder:
   Direct-Tax-Litigation-Tracker

9. PRIVACY
   This is an academic demonstration application.
   Do not enter real taxpayer/client information.
   The GitHub submission does not include the local database.

10. TROUBLESHOOTING

   If npm is not recognized:
      Install Node.js, close the terminal, open a new terminal,
      and verify:
         node --version
         npm --version

   If localhost is refused:
      Make sure:
         npm run dev
      is still running, then open the URL shown in the terminal.

For full details, read README.md.
